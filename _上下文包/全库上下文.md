# 连锁标准化与督导 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
**标准化**：把样板店全套标准打包成"开店包" → 复刻到新店 → 督导验收过关才转正。
**督导**：拉巡检表逐维度打分 → 一票否决项零容忍 → 问题限期整改 → 复查 → 回流总部(闭环)。

## 几条铁律
1. **SOP 可复制性 = 连锁命根**：标准只在老师傅脑子里 = 开不了第二家好店。一切靠手口传 → 必须沉淀成开店包。
2. **开店包七件套必须齐**：SKU 配方卡 / 设备清单 / 动线布局图 / 岗位编制排班模板 / 培训手册 / 物料清单 / 开业 SOP。缺一件,新店复制就会走样。
3. **督导不止打分,必须闭环**：发现问题 → 限期整改 → 复查 → 回流总部台账。只打分不复查 = 督导白做。
4. **飞检照真实状态**：例行巡店容易"作秀",不提前通知的飞行检查才能查出真实运营。
5. **食安/证照/健康证一票否决**：命中任一 → 直接红牌,不论其他维度多高分;新店缺证 🔴 不得开业(呼应 [`../../90-governance/行业合规默认.md`](../../90-governance/行业合规默认.md))。
6. **配方红线**：配方/央厨工艺 🔴 受限,分级授权,非定版不外传。

## 新店复制时间线（人话版）
筹建(场地/证照/设备进场) → 培训带教(照培训手册练到达标) → 试营业压测(高峰出餐/动线跑通) → 督导验收(逐维度过关 + 食安证照核查) → 转正运营(进常态督导)。

## 详细资产
- [`context/新店复制流程.md`](context/新店复制流程.md) — 开店包七件套 + 复制时间线 + 成功标准
- [`context/督导巡检表.md`](context/督导巡检表.md) — 可直接用的分维度巡检表 + 飞检 + 整改闭环
- 〔样板店开店包母版〕 — 客户补:本品牌的标准范本

## 判断题
1. 新店要开业,开店包里只有培训手册和物料清单,缺配方卡和动线图 → 能进入复制流程吗?（答：不能。开店包七件套必须齐——SKU 配方卡/设备清单/动线布局图/排班模板/培训手册/物料清单/开业 SOP,缺一件就会走样,标记不可开。）
2. 督导巡检某店：服务、5S、出品都打了高分,但发现 2 名后厨员工健康证过期 → 这店巡检算合格吗?（答：不合格,直接红牌。健康证是一票否决项,不论其他维度多高分。）
3. "例行巡店"和"飞行检查(飞检)"有什么本质区别?为什么要飞检?（答：例行巡店提前通知、门店容易临时作秀;飞检不通知、查的是真实运营状态。靠飞检才能发现日常真问题。）
4. 新店试营业各项都顺,但《食品经营许可证》还在办理中 → 督导能判定"通过验收、可转正运营"吗?（答：不能。证照是一票否决项,缺证 🔴 停止 + 人工确认,agent 不得拍板开业/转正。）

7. 新店复制时间线的五个阶段按顺序是?转正前必过哪一关?（答：筹建 → 培训带教 → 试营业压测 → 督导验收 → 转正运营;转正前必过督导验收 + 食安证照核查。）

# 招商加盟合规处置（操作 SOP）

> 补盲区：库原无加盟业务线，但连锁品牌高频开放加盟。本卡管"加盟时配方/财务怎么给、招商怎么宣传才合规"，加盟咨询归本工作流（连锁标准化的自然延伸）。
> 核心：加盟可以做，但**命脉资产分级授权、商业机密不外泄、招商宣传不踩虚假承诺**。

## 给加盟商什么、怎么给（分级授权）
| 资产 | 默认权限 | 给加盟商的方式 |
|---|---|---|
| 配方卡/中央厨房工艺 | 🔴 受限（连锁命脉）| **绝不打包原文外发**；签约 + 保密协议后，以运营手册/标准化形式分级授权 |
| 进货价/单店真实财务/底价 | 🔴 核心商业机密 | **永不对外**；对加盟商只展示**脱敏的成本结构示意/盈利模型**，非真实底价 |
| 招商手册/样板店展示 | 🟢 对外（须合规审核）| 可给，但须经合规审核、内容真实不夸大 |

## 招商宣传红线（招商手册/话术）
- 🔴 禁收益保证：不得写"稳赚/X 个月回本/保证盈利/包成功"等承诺（涉虚假宣传/欺诈）。
- 收益须用"参考/因经营而异"口径，不与个别样板店挂钩误导。
- 须依法做**商业特许经营信息披露**；具备"两店一年"等特许经营条件并按规备案（《商业特许经营管理条例》）。

## agent 标准动作
1. 加盟咨询/招商内容 → 走本卡，不绕过。
2. 有人要"配方卡+财务打包发加盟商" → **拒绝原文外发**，改走"签保密协议 + 分级授权运营手册 + 脱敏盈利模型"，转招商/法务。
3. 招商文案出现收益保证/回本承诺 → 拦截改稿，去保证性表述。
4. 加盟合同/信息披露 → 必须法务 + 人工确认，agent 不自拟。

## 标准话术（老板要打包配方+财务给加盟商时）
"配方和单店真实财务是咱们的命脉和商业机密，不能原文打包外发。合规做法：加盟商签保密协议后，给标准化运营手册（不是配方原文）+ 脱敏的盈利模型示意，具体条款我转招商负责人和法务。"

| 件 | 内容 | 解决的问题 |
|---|---|---|
| ① SKU 与配方卡 🔴 | 每道菜的用料、克重、工艺步骤、出品标准图 | 出品一致性（同一个味道）|
| ② 设备清单 | 设备型号/数量/摆位/采购或租赁来源 | 后厨产能与复刻一致 |
| ③ 动线布局图 | 前厅+后厨平面图、动线走向、工位分布 | 高峰不堵、效率可复制 |
| ④ 岗位编制与排班模板 | 各岗人数、班次、高峰加排规则 | 人效达标、不缺岗不冗员 |
| ⑤ 培训手册 | 各岗操作 SOP、考核点、带教节奏 | 新人练到达标的依据 |
| ⑥ 物料清单 | 食材/包材/易耗品 SKU + 首批进货量 | 开业不断货、不囤货 |
| ⑦ 开业 SOP | 开业前 N 天倒排清单、试营业脚本、开业当天流程 | 开业不手忙脚乱 |

> ⚠️ 配方卡（①）属 🔴 受限,分级授权、非定版不外传,引用必脱敏。开店包不齐 → 标记**不可开**,不得进入复制流程。

## 第二步：新店复制时间线（五阶段倒排）

```
筹建            场地交付 / 证照办理(营业执照+食品经营许可证) / 设备进场调试 / 首批物料到位
  ↓
培训带教        照培训手册练 → 各岗考核达标 → 后厨配方卡练到出品一致
  ↓
试营业压测      高峰出餐压测 / 动线跑通 / 出餐时长达标 / 试营业脚本走一遍
  ↓
督导验收 ★关卡   按督导巡检表逐维度过关 + 食安证照健康证核查(一票否决)
  ↓
转正运营        进入常态督导节奏,纳入例行巡店+飞检
```

> 督导验收是**硬关卡**：不过关不转正。食安/证照/健康证命中 🔴 → 停止 + 人工确认,agent 不得判定可开业。

## 第三步：复制成功标准（验收看这三条）

| 维度 | 标准 |
|---|---|
| 出品一致性 | 与样板店出品对照,达标率 ≥〔占位 %〕 |
| SOP 落地率 | 培训手册各岗 SOP 实操达标率 ≥〔占位 %〕 |
| 首月达标线 | 首月翻台率/客单价/食材成本率达〔占位线〕 |

## 用法
新店复制第一步永远是核开店包七件套是否齐全(缺项不可开),再按时间线推进,转正前必过督导验收。复制中暴露的"哪个标准没落地" → 回流补全开店包母版（见 [[督导巡检表]] 的整改闭环）。

# 督导巡检表（脱敏示范，可直接用）

> 核心：**督导不止打分,必须闭环——发现问题 → 限期整改 → 复查 → 回流总部。只打分不复查 = 督导白做。**
> 食安/证照/健康证为**一票否决项**,命中直接红牌,不论总分（呼应 [[行业合规默认]]）。
> （权重/分值/红黄牌线为占位,客户按品牌标准填。）

## 一、分维度巡检打分项（逐项打分）

| # | 维度 | 主要检查项（agent 逐项核） | 否决? |
|---|---|---|---|
| 1 | **食品安全与卫生** | 明厨亮灶到位 / 留样合规 / 食材无过期变质 / 无地沟油等高危行为 / 索证索票台账齐 | 🔴 一票否决 |
| 2 | **证照与健康证** | 营业执照+食品经营许可证有效悬挂 / 全员健康证有效 / 涉酒等许可齐 | 🔴 一票否决 |
| 3 | **库存与效期** | FIFO 先进先出 / 临期效期标识 / 冷链温度达标 / 报损隔离规范 / 账实相符 | 命中变质即转 1 |
| 4 | **出品一致性** | 配方卡用料克重达标 / 出餐时长达标 / 出品对照样板店达标率 / 摆盘标准 | 打分项 |
| 5 | **服务标准** | 接待话术 / 响应速度 / 投诉处理 / 着装仪容 | 打分项 |
| 6 | **现场 5S** | 整理/整顿/清扫/清洁/素养 / 设备保养 / 工位整洁 | 打分项 |
| 7 | **营销执行** | 当期活动物料到位 / 券核销规范 / 价格明码标价无欺诈 | 打分项 |

> 评分：维度 1、2 为一票否决,命中任一 → **直接红牌**,不论其他维度多高分;agent 不得判定门店"巡检合格"。

## 二、飞行检查（飞检）机制

- **为什么飞检**：例行巡店提前通知,门店易临时作秀;**飞检不通知,查的是真实运营状态**。
- **怎么飞**：不预告时间、随机选店、直奔后厨与效期区(最易出问题的地方)。
- **频次**：〔占位：每店每季 ≥N 次〕,问题店加密。

## 三、评分与红黄牌处置

| 结果 | 触发条件（占位线） | 处置 |
|---|---|---|
| 🟢 绿牌 | 总分 ≥〔占位〕且无否决项 | 通过,常态督导 |
| 🟡 黄牌 | 总分〔占位区间〕或有非否决类问题 | 限期整改 + 复查 |
| 🔴 红牌 | 命中食安/证照/健康证否决项,或总分 <〔占位〕 | 立即处置 + 人工确认升级,严重者停业整顿 |

## 四、整改闭环（督导的命根，不止于打分）

```
发现问题        巡检/飞检逐项记录,列问题清单(分维度+严重度)
  ↓
限期整改        下整改单,定责任人+整改期限
  ↓
复查            到期复查,核实是否真改(否决项必现场复查,不接受口头)
  ↓
回流总部        整改结果回流总部台账 → 反复出现的问题回流开店包/培训手册母版迭代
```

## 用法
拉表 → 选类型(例行/飞检)→ 逐维度打分 → 否决项零容忍 → 出问题清单 → 走整改闭环。反复出现的问题不只是单店整改,要回流总部把标准补进 [[新店复制流程]] 的开店包,从源头杜绝。

# 会员与复购 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
结账即入会发首单券 → RFM 打标分四层 → 按层定节奏触达 → 7 日催二单、活跃推储值、沉睡主动唤醒 → 外卖按 SOP 配价控评 → 回收复购率迭代。

## 几条铁律
1. **入会做成动作的一环**：扫码入会绑在结账/出餐环节，别靠顾客自觉，断点 = 会员池漏水。
2. **分层触达，禁全员群发**：高频/活跃/沉睡/流失四层走不同话术与权益，一套话术群发既骚扰常客又救不回沉睡客。
3. **沉睡主动唤醒**：盯住 N 天没来的人，限时唤醒券主动捞，别等彻底流失才动。
4. **储值锁定活跃客**：把高频活跃客转储值/付费会员，提前锁定下一轮消费。
5. **外卖食安封签红线**：外卖必贴封签，破损即拒收，呼应合规默认。
6. **差评不承诺超额赔偿**：差评按话术安抚解决，涉赔偿/食安投诉 🔴 走人工，agent 不擅自承诺。
7. **隐私红线**：顾客手机/微信/订单/会员数据 🔴 受限，绝不外发，引用必脱敏。

# 会员分层与复购节奏（脱敏示范）

> 核心：**别用一套话术群发所有人。按 RFM 分四层，按层定节奏触达。**
> （天数/券面额/储值档为示意占位，客户填自己的真实设置）

## 第一步：入会（把池子先攒起来）
- 到店扫码 → 进企微 / 社群 / 小程序会员，绑进**结账或出餐动作**，禁靠顾客自觉（断点 = 漏水）。
- 入会即发**新客首单券**（示意：满〔X〕减〔Y〕），当场用或下次用，制造二次到店理由。
- 外卖顾客：随单卡片/短信引导加企微入会，承接到私域。

## 第二步：RFM 分层（30 秒判层，决定打法）
按 最近一次消费（R）/ 消费频次（F）/ 消费金额（M）三维判：

| 层 | 信号（示意阈值，客户填真实值） | 核心打法 |
|---|---|---|
| 🔴 高频 | 近〔30〕天来 ≥〔4〕次 / 客单稳定 | 转储值 + 付费会员，给专属权益，锁定下一轮，别再发普通新客券 |
| 🟠 活跃 | 近〔30〕天来 〔2-3〕次 | 推连带/拼单券提客单，引导升储值 |
| 🟡 沉睡 | 上次消费 〔30-60〕天前、之后没来 | 限时唤醒券主动捞，唤回到店 |
| ⚪ 流失 | 上次消费 >〔60〕天 | 末次强钩子唤醒，无效转长期低频触达，不死缠 |

## 第三步：分层触达节奏表（按层走，禁群发）

| 节点 | 对象 | 动作 | 权益（示意） | 指标 |
|---|---|---|---|---|
| 入会当天 | 新客 | 欢迎语 + 首单券 | 满〔X〕减〔Y〕 | 入会率 / 首单核销率 |
| 第 7 天 | 新客未二次到店 | 推二次到店钩子 | 二单券 | 二单转化率 |
| 第 15-30 天 | 活跃客 | 提客单 + 引导储值 | 储值返〔Z〕% | 储值转化率 / 连带率 |
| 沉睡触发 | 沉睡客 | 限时唤醒 | 唤醒券（短有效期） | 唤醒到店率 |
| 流失触发 | 流失客 | 末次强钩子 | 高价值招回券 | 招回率 |

## 第四步：盯指标（每轮触达回收，回流数据）
- **复购率** = 周期内再次消费会员数 ÷ 会员总数（餐饮 LTV 核心）
- **核销率** = 已核销券数 ÷ 发券数（衡量券设计与节奏是否对）
- **储值转化率** / **唤醒到店率** / **二单转化率**：分别诊断各层节奏效果
- 基线见 〔历史复购数据〕，触达后对比迭代阈值与券面额。

# 外卖运营 SOP（脱敏示范）

> 核心：**外卖是另一套生意——定价覆盖佣金、出餐卡时效、评分靠运营、食安靠封签。**
> （佣金率/价格/时效为示意占位，客户填自己平台的真实数字）

## 一、菜单结构与定价（先把账算对）
- **堂食/外卖差异化定价**：外卖售价须覆盖平台佣金（示意〔20〕%）+ 包装成本，不能照搬堂食价，否则毛利被吃穿。
- **菜单结构**：设引流品（低价拉新客券）+ 利润品（撑毛利）+ 凑单品（提客单到满减门槛）。
- **套餐设计**：主食 + 小食 + 饮品打包，提客单价与连带率，降单均配送占比。
- **精简 SKU**：外卖出餐快为王，砍掉出餐慢/包装易洒的品。

## 二、活动配置（拉新 + 提单 + 控成本）
- **满减阶梯**：设满〔A〕减〔B〕、满〔C〕减〔D〕，门槛卡在略高于平均客单，引导凑单。
- **新客券**：针对平台新客发首单券拉新，老客走会员体系（见 [[会员分层与复购节奏]]）。
- **折扣 / 折扣商品**：用引流品做折扣冲排名，但守住整体毛利红线，不亏本冲量。
- **避免活动叠加穿底**：满减 + 折扣 + 平台补贴叠加前先算到手价，防负毛利。

## 三、出单与履约时效（体验命门）
- **接单即确认**：高峰期不漏单、不超时接单。
- **出餐时效**：盯**出餐时长**与**超时率**，高峰期备好半成品/料理包缩短出餐。
- **骑手取餐动线**：设独立外卖取餐口/取餐架，骑手进店即取即走，不与堂食动线冲突，减少等待与差评。
- **缺品处理**：售罄及时下架，避免接单后缺品引发差评/退款。

## 四、包装与食安（🔴 合规红线，对外动作前必过）
- **食安封签**：外卖订单**必贴食品安全封签**，封签破损视为可能被动过，骑手/顾客可拒收——这是硬性合规，不可省。
- **保温与防洒**：汤品/易洒品独立密封 + 防洒包装；冷热分装；保温袋按品类配。
- **包装标注**：套餐含已知过敏原应可说明，不虚假标注分量/产地（呼应合规默认）。
- 包装破损/封签缺失导致的食安风险 → 按合规默认走应急，不擅自承诺赔偿。

## 五、评分与差评处理（守住店铺权重）
- **盯评分**：评分直接影响平台排名与曝光，低分 = 流量下滑，作为日常核心指标。
- **差评分类处理**：
  - 出餐慢/漏餐/包装问题 → 诚恳致歉 + 解释改进 + 在权限内补偿（小额补偿券），不承诺超额。
  - 口味/分量主观差评 → 感谢反馈 + 邀请再体验，不争辩。
  - **涉食安/异物/食物中毒/要求高额赔偿** → 🔴 立即停手走人工 + 隔离取证 + 通知 DRI，**agent 不得承诺超额赔偿、不擅自答复**（呼应 行业合规默认 食安应急）。
- **差评话术红线**：所有回复不承诺超出门店标准的赔偿；不暴露顾客手机/订单等隐私（🔴 受限）。

## 用法
外卖与堂食是两套打法。先把定价账算对（覆盖佣金），再配活动、控时效、贴封签、盯评分。新客拉进来后承接到私域会员体系做复购。顾客数据 🔴 受限，对外脱敏。

# 拓店选址筹建 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
过否决项 → 核证照可办性 → 打分卡量化横评 → 阈值判级 → 签约（最后再核证照）→ 启动筹建（证照为关键路径）→ 试营业压测 → 三道合规闸全过 → 正式开业。

## 几条铁律
1. **否决项先于打分**：排烟不可解/物业禁餐饮/证照不可办/水电排污不达标且不可改 —— 命中一条，分数再高也不签。

3. **不凭感觉签约**：实地数人流、保守测租售比，用打分卡横评多点位。
4. **缺证不得开业**：证照齐全才能营业，这是红线，agent 不得拍板放行。
5. **持证上岗 + 明厨亮灶**：员工必须持有效健康证才排班；后厨必须达明厨亮灶标准。
6. **隐私/机密红线**：供应商报价、单店财务、租金底价 🔴 受限；证照原件 ⛔ 禁止入库。

## 筹建阶段甘特（六段并行/串行，关键路径是"证照")
```
签约
 ├─ ① 证照办理（关键路径，最先启动）───────────────┐
 ├─ ② 设计施工（消防/排烟/明厨亮灶）──────┐         │
 │        └─ ③ 设备采购进场 ──┐          │         │
 │                            ↓          ↓         ↓
 ├─ ④ 招聘培训（健康证）─────────────────┘         │
 │                                                  ↓
 └────────────────────→ ⑤ 试营业压测 ──→ ⑥ 正式开业
```
> ⚠️ 证照办理周期最长、最不可控，**签约当天即启动**，否则它会卡死整个开业日期。

## ① 证照办理（🔴 关键路径，不齐不得营业）
- [ ] 《营业执照》（核对经营范围含餐饮/食品）
- [ ] 《食品经营许可证》（功能分区、面积、设备需先达标才受理）
- [ ] 《排污许可》/ 环保手续（油烟、污水）
- [ ] 消防：消防安全检查合格 / 二次消防报审（如需）
- [ ] 涉酒类、户外摆台、特殊品类的对应许可
> 缺任一证 → 🔴 不得开业/试营业，agent 不得拍板放行，上报 DRI 人工确认。

## ② 设计施工（合规优先于美观）
- [ ] 平面布局符合食品经营许可功能分区（生熟分开、洗消区、库房）
- [ ] **排烟系统**：油烟净化达标、烟道走向经物业/环保认可
- [ ] **消防工程**：通道、报警、灭火设施按报审执行
- [ ] **明厨亮灶**：透明厨房/视频公示/玻璃隔断（满足当地标准之一，呼应合规红线）
- [ ] 上下水、隔油池、强弱电按餐饮负荷施工

## ③ 设备采购进场
- [ ] 厨房设备清单按出餐 SOP 配齐（灶/冰柜/操作台/洗消）
- [ ] 冷链设备到位并验温（冷藏/冷冻达标，呼应温度管控红线）
- [ ] 前厅设备（收银/POS/桌椅/外卖打包台）
- [ ] 设备进场与施工节点对齐，避免装修返工

## ④ 招聘培训（🔴 健康证红线）
- [ ] 按编制招齐前厅/后厨
- [ ] **所有接触直接入口食品的员工持有效《健康证》方可上岗**（无证/过期 → 不得排班）
- [ ] 出餐 SOP / 服务 SOP / 食品安全培训到位
- [ ] 索证索票、留样、FIFO、报损流程培训并考核

## ⑤ 试营业压测
- [ ] 证照确认齐全后方可试营业（缺证不得试营业）
- [ ] 全员健康证齐全后方可排班
- [ ] 高峰压测：出餐时长、动线、设备负荷
- [ ] 留样制度、温度记录、台账当天即跑起来
- [ ] 收集问题清单 → 整改 → 复评

## ⑥ 正式开业
- [ ] 证照齐全 + 全员持证 + 明厨亮灶达标 三项全过（任一不过 → 不得开业）
- [ ] 食安自查表过关
- [ ] 开业活动物料经合规审核（菜单/海报不得虚假夸大）

## 用法
点位过评后照此清单推进筹建，证照是关键路径需最先启动。三道合规闸（证照齐全 / 持证上岗 / 明厨亮灶）任一不过 → agent 立即停止开业并上报。

# 选址评分模型 · 量化打分卡（脱敏示范）

> 拓店第一步。**先过否决项 → 再核证照可办性 → 最后才打分。** 否决项命中一条，分数再高也不签。
> （所有红线数字用「〔〕」占位，客户填自己的真实标准；不要编造）

## 第一步：一票否决项（命中任一 → 直接 PASS，不进入打分）
- ⛔ **排烟无法解决**：油烟无合规外排路径 / 楼上住户必然投诉且无整改空间。
- ⛔ **物业禁餐饮**：产权或物业明确禁止餐饮业态（含"禁明火""禁排油烟"等等效条款）。
- ⛔ **证照不可办**：该地址无法办出《食品经营许可证》（如住改商受限、消防不过、楼栋性质不符）→ 见下方"签约前必查证照可办性"。
- ⛔ **供电/供水/排污不达标且无法改造**：餐饮所需电量/上下水/隔油排污达不到且物业不允许增容改造。

> 否决项是"生死线"，不是扣分项。agent 一旦识别命中 → 🔴 停止推进 + 标注原因，不得用其他维度高分对冲。

## 第二步：签约前必查证照可办性（呼应合规红线，缺一不可）
1. 地址性质能否办《营业执照》（住宅/商业/工业性质核对）。
2. 该址能否办《食品经营许可证》（经营项目、面积、功能分区是否满足当地受理口径）。
3. 排烟/排污是否满足环保受理（必要时需《排污许可》或环评）。
4. 消防是否可通过（是否需二次消防报审、有无前置改造）。
> ⚠️ 三道证照（营业执照 / 食品经营许可证 / 排污）任一办不出 = 等同否决项。**证照可办性不确认，不得签约。** 详见 [[筹建开业Checklist]] 的证照办理段。

## 第三步：量化打分卡（满分 100，权重客户可调）
| 维度 | 权重示例 | 看什么 | 评分要点 |
|---|---|---|---|
| 客流量 | 〔20%〕 | 日均人流、时段分布 | 实地分早/午/晚/周末数人流，别只信中介口径 |
| 人流动线 | 〔10%〕 | 人往哪走、进店是否顺路 | 在"回家/上班/逛街"主动线上为佳，逆动线扣分 |
| 可见性与门头展示面 | 〔10%〕 | 门头宽度、招牌可视距离、有无遮挡 | 展示面越宽越正越好；被树/柱/拐角挡 = 扣分 |
| 商圈匹配度·品类适配 | 〔15%〕 | 商圈客群与本品类是否对味 | 客单价/品类与周边消费力匹配，错配是慢性死亡 |
| 竞品与互补业态 | 〔10%〕 | 直接竞品数量、互补业态聚集度 | 适度竞争=有需求；互补业态(影院/商超)带客流加分 |
| 租金与坪效测算 | 〔15%〕 | 月租、租售比、预估坪效 | 用保守营业额测租售比，超〔租金占营收 X%〕红线扣分 |
| 物业条件(供电/供水/排烟/排污) | 〔10%〕 | 电量、上下水、烟道、隔油排污 | 不达标但可改造=扣分计改造成本；不可改造=否决 |
| 停车与外卖骑手动线 | 〔5%〕 | 顾客停车、骑手取餐顺不顺 | 外卖占比高的品类，骑手动线权重应上调 |
| 合同条款 | 〔5%〕 | 租期/递增/免租期/转让费 | 租期短、递增高、免租期短、转让费高 → 逐项扣分 |

### 合同条款细看（容易被忽视，单列）
- **租期**：太短摊不平投资，争取〔X 年〕以上。
- **递增**：年递增〔X%〕以内可接受，阶梯递增看总账。
- **免租期**：装修期免租至少〔X 天/月〕，写进合同。
- **转让费**：是否合理、是否有合法依据、能否分摊回收。

## 打分判级（阈值客户填）
| 总分 | 结论 | 动作 |
|---|---|---|
| ≥〔85〕 | 优质点位 | 走筹建流程，进 [[筹建开业Checklist]] |
| 〔70-84〕 | 合格点位 | 谈判优化条款/改造方案后复评 |
| 〔60-69〕 | 边际点位 | 需 DRI 评审，慎签 |
| <〔60〕 | 不合格 | PASS |

> 任何分数前置：**否决项 + 证照可办性先过**。这两关不过，打分结果一律作废。

## 用法
拓店第一步即用本卡逐点位打分横评，避免凭感觉签约。签约前最后一道闸是证照可办性。点位定下 → 交 [[筹建开业Checklist]] 启动筹建。

# 门店运营 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
开店三查（备料/设备/卫生）→ 标准出餐（一致 + 快）→ 高峰调度（排班/限流/叫号/话术）→ 营业中巡检 → 收市盘点（清洁/对账/留样/废弃物）。

## 几条铁律
1. **出品一致性是连锁的命**：严格照标准 Recipe + 标准分量，凭手感 = 砸招牌。
2. **速度服务于翻台**：盯出餐时长目标〔占位〕，但快不能牺牲一致与安全。
3. **高峰靠提前排，不靠临时救**：排班峰谷匹配，备料按峰量备足，叫号限流稳住等位体验。
4. **食品安全是生命线**：三时段卫生检查、温度/保质期/FIFO、留样、明厨亮灶，一项不达标就停。
5. **健康证红线**：健康证缺失/过期的员工，不得排班上岗。
6. **食安事件不擅自承诺**：异物/不适投诉 → 隔离取证 + 上报 DRI，agent 不替门店答复赔偿。
7. **隐私红线**：顾客信息 🔴 受限，配方 🔴 受限，对外引用必脱敏。

## 核心指标
- **翻台率** / **出餐速度（出餐时长）** / **出品一致性** —— 门店运营的三个北极星。
- 辅助：高峰积单数、巡检合格率、报损率、留样合规率。

# 出餐 SOP 与高峰期管理

> 核心：**出品一致 + 出餐快**是门店运营的两条命。一致靠标准 Recipe，快靠提前排产与高峰调度。
> （出餐时长目标 / 备料量 / 排班人数为客户专属，用〔〕占位，填自己门店真实标准。）

## 一、开店准备（开门前）
- **备料**：按〔当日预估客流/峰量〕备足净菜、半成品、料包；遵守 FIFO，临期食材优先用、过期立即报损隔离。
- **设备检查**：灶具/冰柜/保温/制冰/收银/叫号系统逐项通电测试；冷藏/冷冻温度达标（详见 [[食品安全与卫生标准]]）。
- **卫生**：开业前卫生检查项全过（详见 [[食品安全与卫生标准]]）；员工健康证、穿戴、洗手到位才上岗。
- 三项任一不达标 → 整改后才开门；命中食安隐患 → 🔴 停，走食安流程。

## 二、接单出餐标准流程
1. **接单**：前厅录单 → 后厨叫单/打印，确认桌号、品项、特殊要求（少辣/忌口/过敏原）。
2. **标准 Recipe**：严格按〔标准 Recipe〕操作工序，不凭手感、不省步骤——这是出品一致性的唯一基准。
3. **标准分量**：按〔标准分量表〕称量/控量，杜绝多给少给造成的成本与体验波动。
4. **出餐时长**：盯〔出餐时长目标（占位）〕，从下单到上桌计时；超时单记录回流。
5. **前后厨协同**：后厨出餐 → 划单/报菜 → 前厅传菜核对桌号品项 → 漏单/错单当场纠。
6. **出品检查**：出门前看卖相/温度/分量，不达标即返工，不让次品出门。

## 三、高峰期管理
- **排班峰谷匹配**：按〔峰谷客流数据〕排班，午晚高峰加岗、平峰减岗，避免高峰缺人、平峰窝工。
- **备料按峰量**：高峰前完成预制/补料，半成品提前到位，减少现场加工时间。
- **限流与叫号**：满座时启用叫号/取号，控制进店节奏，避免后厨爆单导致全面超时。
- **加单/安抚话术**：用标准话术管理等位与催菜预期（如告知预计等位时长、主动报菜进度），稳住体验。
- **后厨节奏控制**：按叫单顺序控火出餐，先到先做 + 急单插队规则清晰，不积单不漏单。

## 四、收市盘点（打烊后）
- **清洁复位**：后厨/前厅/设备清洁，按收市卫生检查项执行（详见 [[食品安全与卫生标准]]）。
- **盘点对账**：食材/物料实物盘点对账面，标记损耗、临期；报损按流程登记。
- **留样核对**：核对当日各餐次留样是否齐全、标签时间是否规范。
- **废弃物交接**：餐厨垃圾/废油交有资质单位并留台账。
- **报表回流**：当日营业额、出餐超时单、报损、客流回流运营数据，供复盘。

## 核心指标
- **翻台率**：单时段餐桌使用次数，运营效率核心。
- **出餐速度（出餐时长）**：高峰体验与翻台的关键。
- **出品一致性**：连锁可复制的根基，靠标准 Recipe + 标准分量保障。

# 隔夜/熟制食品再销售温控标准（操作 SOP）

> 补盲区：库原只有"过期禁用/报损隔离"的一般红线，本卡给"剩菜到底能不能卖、怎么卖"的可执行阈值。
> 核心：能不能再卖，看**全程温控 + 时限 + 复热 + 性状**四关，任一不过 = 必弃。给的是通用食安标准，本店更严阈值填〔占位〕。

## 四关判定（全过才可再售）
| 关 | 通用标准 | 本店阈值 |
|---|---|---|
| 1 冷藏温控 | 熟食出餐后 2 小时内未售须冷藏（冷藏 ≤8℃ 或 冷冻）；常温久置一律弃 | 〔填本店冷藏温度〕 |
| 2 存放时限 | 冷藏熟食再售存放不超过本店设定时限，超时必弃 | 〔填本店时限，建议 ≤24h〕 |
| 3 复热 | 再售前充分复热至**中心温度 ≥70℃**（高风险品类建议 ≥75℃）；**只可复热一次** | 〔本店若更严填此〕 |
| 4 性状 | 变味/发黏/变色/异味/胀袋 → 一律废弃，不冒险 | — |

## 高风险品类（更严或直接不隔夜再售）
凉拌菜、海鲜水产、蛋制品、奶/豆制品、溏心类 → 建议**当日售罄不隔夜再售**（本店按〔品类清单〕收紧）。

## agent 标准动作
1. 老板/店长问"隔夜 X 能不能卖" → 按四关逐条核：缺温控记录/超时限/不能复热到 70℃/性状异常 → **判不可售、报损**。
2. 四关全过且属可隔夜品类 → 可售，但须复热达标 + 留样。
3. 涉及食安拿不准 → **默认从严禁售**，转门店运营 DRI，宁可报损不冒中毒风险。

## 红线
- 🔴 变质/超时/复热不达标的熟食再售
- 🔴 高风险品类隔夜再售（除非本店明确允许且全程达标）

# 食品安全与卫生标准

> 这是门店运营的**生命线**。一次食安事故可能摧毁整个连锁品牌——宁可保守、宁可停下来核实。
> 全面呼应行业合规默认红线（见 `90-governance/行业合规默认.md`）；各地市监/卫健细则可能更严，以当地《食品安全法》执行口径为准。
> （留样克重/时长、温度阈值等以当地标准与客户内控为准，用〔〕占位。）

## 一、三时段卫生检查
- **开业前**：环境清洁就绪、设备消毒、冷链温度达标、食材新鲜无过期、留样设备就位、员工健康证/穿戴/洗手到位。
- **营业中**：操作台即用即清、生熟分开、刀具砧板分区、垃圾不外溢、温度抽查、洗手频次达标。
- **收市后**：全面清洁消毒、油烟/地沟清理、废弃物分类交接、次日备料隔夜储存合规标记。

## 二、现场管理法
- **五常法（5S）**：常组织、常整顿、常清洁、常规范、常自律——定点定位定量，物品有名有家。
- **4D 现场管理**：整理到位、责任到位、培训到位、执行到位；区域上墙、责任到人。

## 三、个人卫生
- **健康证**：所有接触直接入口食品的员工必须持**有效《健康证》**方可上岗；🔴 过期/缺失 → 不得排班上岗（红线，不因缺人破例）。
- **穿戴**：工作服、帽/发网、口罩、手套按岗位规范穿戴，无外露饰品/长指甲。
- **洗手**：上岗前、如厕后、接触生鲜后、垃圾处理后按规范洗手消毒。

## 四、食材温度与保质期管控
- **冷链不断链**：交收→储存→加工全程冷链；冷藏/冷冻/热存温度达标，记录温度台账。
- **FIFO 先进先出**：先入库先用，标注入库与到期日期。
- **临期/过期处置**：临期优先用并标记，过期/变质一律禁用，立即**报损隔离**，不得回流上餐。
- **索证索票**：进货索取供货资质、检验合格证明、进货台账，做到来源可追、去向可查。

## 五、留样制度
- 按规定对每餐次成品**留样**并记录（通常 ≥〔125g〕、冷藏存〔48 小时〕以上，以当地标准为准），标签注明品名、餐次、留样时间、留样人，供溯源。

## 六、明厨亮灶与废弃物
- **明厨亮灶**：透明厨房/视频公示/玻璃隔断（满足当地标准之一），督导巡检必查。
- **餐厨废弃物**：餐厨垃圾、废弃油脂交**有资质单位**回收并留台账；🔴 严禁私自处置、严禁回收复用废油（地沟油，刑事级红线）。

## 七、食安事件应急上报
1. 触发：异物投诉 / 疑似变质 / 顾客身体不适 / 飞检发现重大隐患。
2. 处置：**立即隔离涉事食材与成品、保留现场与样本取证** → 第一时间通知〔运营 DRI〕→ 走应急上报流程。
3. 🔴 红线：**agent 不得擅自答复顾客、不得承诺赔偿**，由人工/DRI 按流程处置；对外口径需合规审核。

## 食安红线速查（动手前逐条过）
| 项 | 要求 | 违反后果 |
|---|---|---|
| 健康证 | 持有效证上岗 | 🔴 不得排班 |
| 明厨亮灶 | 符合当地标准 | 督导必查 |
| 索证索票 | 来源可追 | 重大隐患 |
| 温度/FIFO | 达标不断链 | 报损隔离 |
| 留样 | 按规留存 | 无法溯源 |
| 废弃物 | 资质单位处置 | 刑事/重罚 |
| 禁高危 | 不用过期/不明食材、不回收废油、不超量添加 | 刑事/重罚 |

# 供应链与采购 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
核供应商资质比价定点 → 按预测下单 → 到货过 5 项验收 → 不合格拒收留证 → 合格入台账按 FIFO 上架 → 冷链不断链 → 算成本率 → 超标走排查清单归因整改。

## 两条命脉
**命脉一：成本率守住**——食材成本率是餐饮命门，目标区间〔30%~40%占位〕。超标四大归因：采购涨价、损耗、出品分量失控、盗损。靠标准 Recipe 卡控分量、菜单工程（高毛利爆品搭配）抬整体毛利。
**命脉二：食品安全不出事**——索证索票、进货台账、冷链不断链、拒收变质，是不可逾越的合规红线（见 [`../../90-governance/行业合规默认.md`](../../90-governance/行业合规默认.md)）。

## 几条铁律
1. **索证索票齐才下单**：供货资质 + 检验检疫合格证明缺一不可，缺证不进货。
2. **到货必验五项**：数量 / 质量 / 温度 / 保质期 / 检疫证明，一项不合格即拒收，不入库不上账。
3. **每笔进货上台账**：来源可追、去向可查，台账缺失 = 重大隐患。
4. **冷链不断链 + FIFO**：温度全程达标，先进先出，临期过期立即报损隔离。
5. **成本超标必归因**：不是只看数字红了，要定位到底是涨价、损耗、分量还是盗损。
6. **数字红线**：供应商报价 / 进货价 / 毛利率 🔴 受限，绝不外发，引用必脱敏。

## 判断题
1. 这个月某店食材成本率从〔目标率〕飙到〔目标率+8%〕，第一步该判断什么？（答：先归因——不是直接换料/提价，按「成本率异常排查清单」逐项查：采购是否涨价、损耗是否变高、出品分量是否失控、有无盗损，定位到具体原因再动手）
2. 一批冷冻肉到货，中心温度明显高于标准、外包装有解冻复冻痕迹，但供应商说"赶时间先收了吧" → 怎么判、怎么处理？（答：判不合格，走拒收流程，不入库不上账，拍照留证 + 通知 DRI，绝不因供应商催促放行——冷链断链是食安红线）
3. 想新增一家更便宜的蔬菜供应商，对方暂时拿不出检验检疫合格证明 → 能先用吗？（答：不能。索证索票齐全才可下单，缺证不进货；更换主力供应商还需人工确认）

## 动作题
4. 食材成本率怎么算？目标区间是多少？（答：食材成本率 =（期初库存 + 本期进货 − 期末库存）÷ 同期营业额 ×100%，即"实际耗用食材成本 ÷ 营业额"；目标区间〔30%~40%占位〕，以本店定版红线为准）
5. 合格食材入库的标准动作顺序是什么？（答：录进货台账（来源可追）→ 按 FIFO 先进先出上架 → 冷藏/冷冻/热存温度达标不断链）
6. 排查成本率超标，发现进货价没涨、盘点账实相符，但某爆品成本异常高 → 最可能的归因和整改是什么？（答：出品分量失控，整改＝回推标准 Recipe 卡，按标准分量重新培训出品，复盘后监控复发）

## 红线题
7. 哪些东西属于 🔴 受限、绝不能写进对外产物？（答：供应商报价 / 进货价 / 毛利率 / 单店财务数据 / 核心配方工艺——引用必脱敏）
8. 食品安全上，采购验收环节哪几条是不可逾越的红线？（答：索证索票齐全才进货、到货五项验收不合格必拒收、进货台账来源可追去向可查、冷链不断链、过期临期变质立即报损隔离禁用——命中即 🔴 停止 + 人工确认）

- 全对：可独立上手 ｜ 6-7 对：需带教 ｜ ≤5 对：重读 context

# 采购验收与溯源 SOP

> 从供应商到入库的标准动作。**索证索票、进货台账、冷链不断链是食安合规红线**（呼应 [行业合规默认](../../../90-governance/行业合规默认.md)），一项不漏。
> （报价/进货价 🔴 受限，对外引用必脱敏。）

## 一、供应商管理（采购前）
1. **索证索票**：每家供货方必须提供——供货资质（营业执照、食品经营/生产许可证）、随货检验检疫合格证明 / 检测报告。缺证 → 不下单。
2. **供货资质留档**：资质入〔供应商档案〕，定期复核有效期，过期前预警换证。
3. **比价定点**：同品类多家比价，择优定点；价格只是一项，资质与稳定供货同等重要。更换主力供应商需人工确认。

## 二、下单（采购）
- 按销量预测 + 当前库存下单，防积压（增损耗）也防断货（影响出餐）。
- 高周转/易损食材小批勤进；耐储食材按 FIFO 备货。

## 三、到货验收（五项必查，逐项过）
| 项 | 标准 | 不合格处理 |
|---|---|---|
| **数量** | 与订单一致，过磅核重 | 短缺/超量 → 记录，按合同处理 |
| **质量** | 新鲜、无变质腐败、无异物异味、规格达标 | 变质/异常 → 拒收 |
| **温度** | 冷藏/冷冻达标，无解冻复冻痕迹 | 温度超标/断链 → 拒收 |
| **保质期** | 在保质期内且余期充足，无临期混入 | 过期/临期不符 → 拒收 |
| **检验检疫证明** | 随货证明齐全、与货物对应 | 缺证/不符 → 拒收 |

## 四、不合格拒收流程
1. 当场判定不合格 → **不入库、不上台账**。
2. 拍照留证（货物状态 + 温度 + 证明缺失情况）。
3. 通知〔供应商 DRI〕，按合同退换/索赔，记录到供应商档案。
4. **绝不因供应商催促或"赶时间"放行**——温度断链/变质/缺证是食安红线，命中即 🔴 停止 + 人工确认。
5. 同一供应商高频拒收 → 进黑名单复核，回流自我进化接口。

## 五、进货台账与溯源
- 每笔合格进货登记台账：**供货方、品名、规格、数量、进货日期、保质期、检验检疫证明编号、经手人**。
- 做到**来源可追、去向可查**——出问题能反查到批次和供应商。台账缺失 = 重大隐患。
- 配合留样制度（成品按规定留样，见合规默认），形成完整溯源链。

## 六、入库（冷链不断链 + FIFO）
1. 合格食材验收后**第一时间入对应温区**，缩短常温暴露时间，冷链全程不断链。
2. 冷藏 / 冷冻 / 热存温度达标，定时记录温度。
3. **FIFO 先进先出**上架：新货放后/下，旧货放前/上，防过期。
4. 临期食材标识优先消化或报损隔离；过期变质立即报损隔离禁用。

# 食材成本控制法

> 食材成本率（Food Cost）是餐饮第一命门。这页教 agent：怎么算、超标怎么逐项归因、怎么用标准化把成本摁住。
> （所有率值/单价/毛利为示意，客户填自己公司的真实红线数字。报价/进货价/毛利率 🔴 受限。）

## 一、食材成本率怎么算
```
食材成本率 = 实际耗用食材成本 ÷ 同期营业额 × 100%
实际耗用食材成本 = 期初库存 + 本期进货 − 期末库存
```
- 目标区间：〔30%~40%占位〕，以本店定版红线为准（品类不同区间不同）。
- 算之前先盘点：账面与实物对得上，算出来的率才可信。账实不符本身就是信号（损耗/盗损）。

## 二、超标预警与四大归因
率红了不是直接换料提价，先定位原因。四大来源：

| 归因 | 信号 | 整改方向 |
|---|---|---|
| **采购涨价** | 进货价上行、比价表显示供应商提价 | 重新比价/换定点供应商（需人工确认）/调整菜单或分量 |
| **损耗** | 报损量↑、临期过期增多、加工出成率低 | 查 FIFO 执行、冷链温度、加工标准；改进储存与排产 |
| **出品分量失控** | 单品成本异常高、出品忽大忽小 | 回推标准 Recipe 卡，按标准分量重新培训出品 |
| **盗损** | 盘点账实长期不符、库存莫名减少 | 查权限/监控/盘点频次，收紧出入库管理 |

## 三、成本率异常排查清单（agent 可直接照着跑）
1. **先盘点核账**：期初+进货−期末 与系统是否一致？账实不符 → 怀疑损耗/盗损。
2. **查进货价**：对比上期比价表，进货价有没有涨？涨了多少？→ 采购涨价。
3. **查报损/损耗**：报损率是否上升？临期过期是否增多？出成率是否下降？→ 损耗。
4. **查单品成本**：哪个菜的成本率异常？该菜出品分量是否对得上标准 Recipe 卡？→ 分量失控。
5. **查出入库与盘点缺口**：库存有没有对不上账的莫名减少？→ 盗损。
6. **定位后给整改 + 监控复发**：每条异常记录归因 + 整改动作，回流自我进化接口。

## 四、用标准化把成本摁住
- **标准 Recipe 卡控分量**：每道菜定死食材种类、克重、出成，这是分量不失控、成本可算的基准。央厨净菜/半成品更要按卡。
- **报损管理**：变质/过期/操作失误的损失要日清记录、归因，损耗不是"自然现象"是可管的。临期食材按规则优先消化或报损隔离，不得继续用变质品（食安红线）。
- **菜单工程（高毛利爆品搭配）**：把菜品按"毛利高低 × 点击率高低"分四象限——
  - 高毛利高人气＝明星品，重点推、放显眼位；
  - 高毛利低人气＝潜力品，靠搭配/话术带；
  - 低毛利高人气＝引流品，控量或微调分量/定价；
  - 低毛利低人气＝拖累品，考虑下架。
  通过菜单结构而非单纯压价来抬整体毛利。（毛利率属 🔴 受限，对外不披露具体数字。）

> 企业库和个人库最硬的区别。没有权限治理 = AI 资料垃圾场 + 隐私事故。

# 餐饮（连锁）行业 · 合规与权限默认值

> 合成进成品库 `90-governance/行业合规默认.md`。客户可按自身情况收紧。
> ⚠️ 食品安全是餐饮的生命线。任何门店运营、供应链、出餐相关产出，动手前必读本页。各地市监/卫健细则可能更严，以当地《食品安全法》执行口径与监管要求为准。

## 默认权限分级（通用四级 + 餐饮补充）
| 资产类型 | 默认级别 |
|---|---|
| 顾客个人信息（姓名/手机/微信/地址/订单记录/会员数据）| 🔴 受限（永不对外，输出必脱敏）|
| 员工健康证/身份证/劳动合同/薪酬 | 🔴 受限（证件类敏感信息）|
| 供应商报价/进货价/毛利率/单店财务数据 | 🔴 受限（核心商业机密，决定生死）|
| 内部 SOP/出餐标准/服务话术/督导表/选址模型 | 🟡 内部 |
| 配方/中央厨房工艺/核心 Recipe | 🔴 受限（连锁命脉，分级授权，非定版不外传）|
| 对外菜单/品牌介绍/招商物料/门店海报 | 🟢 公开（须经合规审核，见红线）|
| 营业执照/食品经营许可证/排污许可等证照 | ⛔ 禁止入库（证件原件类，留原地建索引）|

## 餐饮行业红线（agent 必须遵守，对外/对内产出前逐条过）
1. **证照齐全才能营业**：门店必须持有效《营业执照》《食品经营许可证》方可经营；涉酒类、户外摆台等需对应许可。任何"新店开业/试营业"动作，先核证照状态，缺证 → 🔴 停止并人工确认，agent 不得拍板开业。
2. **员工持证上岗**：所有接触直接入口食品的从业人员必须持有效《健康证》方可上岗；健康证过期/缺失 → 该员工不得排班上岗。
3. **明厨亮灶**：后厨须符合明厨亮灶要求（透明厨房/视频公示/玻璃隔断等当地标准之一）；督导巡检必查。
4. **食材溯源可查**：进货须索证索票（供货方资质、检验检疫合格证明、进货台账），做到来源可追、去向可查。台账缺失 = 重大隐患。
5. **温度与保质期管控**：冷链不断链；冷藏/冷冻/热存温度达标；先进先出（FIFO）；过期、临期、变质食材一律禁用，立即报损隔离。
6. **留样制度**：按规定对每餐次成品留样并记录（通常 ≥125g、冷藏存 48 小时以上，以当地标准为准），供溯源。
7. **禁高危行为**：不得采购/使用来源不明食材、回收复用餐厨废弃油脂（地沟油）、超范围超量使用食品添加剂、销售过期/变质食品。命中任一 → 这是刑事/重罚级红线。
8. **过敏原与真实标注**：菜单成分、分量、产地、宣传不得虚假夸大；含已知过敏原/特殊配方应可向顾客说明，不得隐瞒。
9. **价格与计量诚信**：明码标价，不得价格欺诈、缺斤短两、强制消费。
10. **餐厨废弃物合规处置**：餐厨垃圾/废油交有资质单位回收并留台账，不得私自处置。

## agent 行为
- 任何涉及**出餐、采购验收、新店开业、对外宣传**的产出 → **先过上面红线**，命中食品安全/证照类 → 🔴 立即停止 + 人工确认，绝不自行放行。
- 涉及顾客个人信息、供应商报价、配方工艺 → 默认 🔴 受限，不写入任何对外产物，引用必脱敏。
- 不确定是否合规 → 默认按更严处理，问负责人。
- 食品安全事件（异物/食物中毒投诉/疑似变质）→ 走应急上报，第一时间隔离取证 + 通知 DRI，agent 不得擅自答复顾客承诺赔偿。

> 食品安全无小事。一次食安事故可能摧毁整个连锁品牌——对内对外都宁可保守、宁可停下来核实。
