# 任务卡 · 拓店选址筹建（site-expansion）· 脱敏示范

> Agent 操作总台。接到"评估点位/横评铺子/算租售比/排筹建计划/核证照"类任务，从这里开始。

## 🎯 目标(Goal)
把一个候选点位，从初筛推进到"签约决策 + 筹建开业落地"，全程不踩三大坑（凭感觉签约/证照可办性没核就签/缺证就开业）。

## 📥 上下文(Context) —— 动手前必读全
1. [`context/选址评分模型.md`](context/选址评分模型.md) — 先过否决项→核证照可办性→再打分
2. [`context/筹建开业Checklist.md`](context/筹建开业Checklist.md) — 签约到开业的筹建甘特与三道合规闸
3. 〔餐饮合规默认〕 — 食品安全/证照红线（真实库 `90-governance/行业合规默认.md`）
4. 〔历史开店/关店复盘〕 — 必须避开的踩坑点位（真实库含此项）

## 🪜 指令(Instructions)
1. 拿到候选点位 → 先过**一票否决项**（排烟不可解/物业禁餐饮/证照不可办/水电排污不达标且不可改）
2. 命中否决项 → 🔴 停止推进 + 标注原因，不用其他维度高分对冲
3. 未命中 → **核证照可办性**（营业执照/食品经营许可证/排污/消防），办不出 = 等同否决
4. 通过 → 用打分卡逐维度量化打分（多点位横评）
5. 按阈值判级 → 优质点位进筹建，边际点位交 DRI 评审
6. 签约前最后一道闸：再确认证照可办性
7. 点位定 → 启动 [`context/筹建开业Checklist.md`](context/筹建开业Checklist.md)，证照办理为关键路径最先启动
8. 试营业/开业前：证照齐全 + 全员持健康证 + 明厨亮灶达标，三项全过才放行

## 🛠 工具(Tools)
〔点位档案读写〕 · 选址打分卡模板 · 〔租售比/坪效测算表〕 · 〔筹建甘特/Checklist 模板〕

## 🔒 权限(Permission)
- 可读：选址模型、筹建 Checklist、合规默认、复盘
- 🔴 受限：供应商报价/单店财务测算/租金底价 → 不得写入任何对外产物，引用必脱敏
- ⛔ 禁止入库：营业执照/食品经营许可证/排污许可等证照原件 → 留原地建索引
- 需人工确认：超预算签约、边际点位拍板、**任何缺证开业/试营业（红线，agent 不得放行）**

## ✅ 验收(Acceptance)
- 否决项先过 ｜ 证照可办性已核 ｜ 打分有量化依据 ｜ 缺证不签不开 ｜ 健康证齐才排班 ｜ 明厨亮灶达标
- 详见 evals.md

# 拓店选址筹建 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
过否决项 → 核证照可办性 → 打分卡量化横评 → 阈值判级 → 签约（最后再核证照）→ 启动筹建（证照为关键路径）→ 试营业压测 → 三道合规闸全过 → 正式开业。

## 几条铁律
1. **否决项先于打分**：排烟不可解/物业禁餐饮/证照不可办/水电排污不达标且不可改 —— 命中一条，分数再高也不签。
2. **证照可办性不确认不签约**：营业执照、食品经营许可证、排污三道办不出 = 等同否决项。
3. **不凭感觉签约**：实地数人流、保守测租售比，用打分卡横评多点位。
4. **缺证不得开业**：证照齐全才能营业，这是红线，agent 不得拍板放行。
5. **持证上岗 + 明厨亮灶**：员工必须持有效健康证才排班；后厨必须达明厨亮灶标准。
6. **隐私/机密红线**：供应商报价、单店财务、租金底价 🔴 受限；证照原件 ⛔ 禁止入库。

## 详细资产
- [`context/选址评分模型.md`](context/选址评分模型.md) — 否决项 + 证照可办性 + 量化打分卡
- [`context/筹建开业Checklist.md`](context/筹建开业Checklist.md) — 签约到开业六段甘特 + 三道合规闸
- 〔餐饮合规默认〕 — 客户对齐：食品安全/证照红线（真实库 `90-governance`）

# 拓店选址筹建 · 验收题库（evals）

> 答不对 = 上下文没带全。对照 `_task-card.md` 与 context 逐项打分。

## 判断题
1. 一个点位客流、动线、可见性都打满分，总分 90，但烟道无法外排、楼上是住户必投诉 → 能签吗？（答：不能。排烟无法解决是一票否决项，分数再高也不签，否决项先于打分）
2. 中介说"这地址肯定能办证，先签了再办" → 该怎么办？（答：不签。证照可办性不确认不签约，营业执照/食品经营许可证/排污办不出 = 等同否决，必须先核可办性）
3. 点位打分 80（合格区间），但年租金递增高、免租期只有几天 → 下一步？（答：先就合同条款谈判优化/改造方案后复评，别急着签；条款是打分维度也是回收账）

## 动作题
4. 拿到一个新候选点位，第一步该干什么？顺序是什么？（答：先过一票否决项 → 再核证照可办性 → 最后才量化打分，不能上来就打分）
5. 点位通过、决定推进，筹建第一件最先启动的事是什么？为什么？（答：证照办理。它是关键路径、周期最长最不可控，签约当天即启动，否则卡死开业日期）
6. 装修完、设备进场，但《食品经营许可证》还没下来，老板想先试营业 → 怎么处理？（答：不行。证照齐全才能试营业/营业，缺证 🔴 停止，agent 不得放行，上报 DRI）

## 红线题
7. 试营业排班发现两名后厨员工健康证还在办 → 怎么办？（答：该两人不得上岗排班。接触直接入口食品必须持有效健康证，无证/过期不得排班）
8. 哪三类信息绝不能写进对外产物或入库？（答：供应商报价/单店财务/租金底价 🔴 受限引用必脱敏；营业执照/食品经营许可证/排污许可等证照原件 ⛔ 禁止入库，留原地建索引）

## 评分
- 全对：可独立上手 ｜ 6-7 对：需带教 ｜ ≤5 对：重读 context

# 筹建开业 Checklist · 从签约到开业（脱敏示范）

> 点位通过 [[选址评分模型]] 后启动。**核心铁律：证照齐全才能营业，员工持健康证才能上岗，后厨必须明厨亮灶。** 缺证 = 🔴 停止开业。
> （工期天数用「〔〕」占位，按品类与城市填自己的真实工期）

## 筹建阶段甘特（六段并行/串行，关键路径是"证照")
```
签约
 ├─ ① 证照办理（关键路径，最先启动）───────────────┐
 ├─ ② 设计施工（消防/排烟/明厨亮灶）──────┐         │
 │        └─ ③ 设备采购进场 ──┐          │         │
 │                            ↓          ↓         ↓
 ├─ ④ 招聘培训（健康证）─────────────────┘         │
 │                                                  ↓
 └────────────────────→ ⑤ 试营业压测 ──→ ⑥ 正式开业
```
> ⚠️ 证照办理周期最长、最不可控，**签约当天即启动**，否则它会卡死整个开业日期。

## ① 证照办理（🔴 关键路径，不齐不得营业）
- [ ] 《营业执照》（核对经营范围含餐饮/食品）
- [ ] 《食品经营许可证》（功能分区、面积、设备需先达标才受理）
- [ ] 《排污许可》/ 环保手续（油烟、污水）
- [ ] 消防：消防安全检查合格 / 二次消防报审（如需）
- [ ] 涉酒类、户外摆台、特殊品类的对应许可
> 缺任一证 → 🔴 不得开业/试营业，agent 不得拍板放行，上报 DRI 人工确认。

## ② 设计施工（合规优先于美观）
- [ ] 平面布局符合食品经营许可功能分区（生熟分开、洗消区、库房）
- [ ] **排烟系统**：油烟净化达标、烟道走向经物业/环保认可
- [ ] **消防工程**：通道、报警、灭火设施按报审执行
- [ ] **明厨亮灶**：透明厨房/视频公示/玻璃隔断（满足当地标准之一，呼应合规红线）
- [ ] 上下水、隔油池、强弱电按餐饮负荷施工

## ③ 设备采购进场
- [ ] 厨房设备清单按出餐 SOP 配齐（灶/冰柜/操作台/洗消）
- [ ] 冷链设备到位并验温（冷藏/冷冻达标，呼应温度管控红线）
- [ ] 前厅设备（收银/POS/桌椅/外卖打包台）
- [ ] 设备进场与施工节点对齐，避免装修返工

## ④ 招聘培训（🔴 健康证红线）
- [ ] 按编制招齐前厅/后厨
- [ ] **所有接触直接入口食品的员工持有效《健康证》方可上岗**（无证/过期 → 不得排班）
- [ ] 出餐 SOP / 服务 SOP / 食品安全培训到位
- [ ] 索证索票、留样、FIFO、报损流程培训并考核

## ⑤ 试营业压测
- [ ] 证照确认齐全后方可试营业（缺证不得试营业）
- [ ] 全员健康证齐全后方可排班
- [ ] 高峰压测：出餐时长、动线、设备负荷
- [ ] 留样制度、温度记录、台账当天即跑起来
- [ ] 收集问题清单 → 整改 → 复评

## ⑥ 正式开业
- [ ] 证照齐全 + 全员持证 + 明厨亮灶达标 三项全过（任一不过 → 不得开业）
- [ ] 食安自查表过关
- [ ] 开业活动物料经合规审核（菜单/海报不得虚假夸大）

## 用法
点位过评后照此清单推进筹建，证照是关键路径需最先启动。三道合规闸（证照齐全 / 持证上岗 / 明厨亮灶）任一不过 → agent 立即停止开业并上报。

# 选址评分模型 · 量化打分卡（脱敏示范）

> 拓店第一步。**先过否决项 → 再核证照可办性 → 最后才打分。** 否决项命中一条，分数再高也不签。
> （所有红线数字用「〔〕」占位，客户填自己的真实标准；不要编造）

## 第一步：一票否决项（命中任一 → 直接 PASS，不进入打分）
- ⛔ **排烟无法解决**：油烟无合规外排路径 / 楼上住户必然投诉且无整改空间。
- ⛔ **物业禁餐饮**：产权或物业明确禁止餐饮业态（含"禁明火""禁排油烟"等等效条款）。
- ⛔ **证照不可办**：该地址无法办出《食品经营许可证》（如住改商受限、消防不过、楼栋性质不符）→ 见下方"签约前必查证照可办性"。
- ⛔ **供电/供水/排污不达标且无法改造**：餐饮所需电量/上下水/隔油排污达不到且物业不允许增容改造。

> 否决项是"生死线"，不是扣分项。agent 一旦识别命中 → 🔴 停止推进 + 标注原因，不得用其他维度高分对冲。

## 第二步：签约前必查证照可办性（呼应合规红线，缺一不可）
1. 地址性质能否办《营业执照》（住宅/商业/工业性质核对）。
2. 该址能否办《食品经营许可证》（经营项目、面积、功能分区是否满足当地受理口径）。
3. 排烟/排污是否满足环保受理（必要时需《排污许可》或环评）。
4. 消防是否可通过（是否需二次消防报审、有无前置改造）。
> ⚠️ 三道证照（营业执照 / 食品经营许可证 / 排污）任一办不出 = 等同否决项。**证照可办性不确认，不得签约。** 详见 [[筹建开业Checklist]] 的证照办理段。

## 第三步：量化打分卡（满分 100，权重客户可调）
| 维度 | 权重示例 | 看什么 | 评分要点 |
|---|---|---|---|
| 客流量 | 〔20%〕 | 日均人流、时段分布 | 实地分早/午/晚/周末数人流，别只信中介口径 |
| 人流动线 | 〔10%〕 | 人往哪走、进店是否顺路 | 在"回家/上班/逛街"主动线上为佳，逆动线扣分 |
| 可见性与门头展示面 | 〔10%〕 | 门头宽度、招牌可视距离、有无遮挡 | 展示面越宽越正越好；被树/柱/拐角挡 = 扣分 |
| 商圈匹配度·品类适配 | 〔15%〕 | 商圈客群与本品类是否对味 | 客单价/品类与周边消费力匹配，错配是慢性死亡 |
| 竞品与互补业态 | 〔10%〕 | 直接竞品数量、互补业态聚集度 | 适度竞争=有需求；互补业态(影院/商超)带客流加分 |
| 租金与坪效测算 | 〔15%〕 | 月租、租售比、预估坪效 | 用保守营业额测租售比，超〔租金占营收 X%〕红线扣分 |
| 物业条件(供电/供水/排烟/排污) | 〔10%〕 | 电量、上下水、烟道、隔油排污 | 不达标但可改造=扣分计改造成本；不可改造=否决 |
| 停车与外卖骑手动线 | 〔5%〕 | 顾客停车、骑手取餐顺不顺 | 外卖占比高的品类，骑手动线权重应上调 |
| 合同条款 | 〔5%〕 | 租期/递增/免租期/转让费 | 租期短、递增高、免租期短、转让费高 → 逐项扣分 |

### 合同条款细看（容易被忽视，单列）
- **租期**：太短摊不平投资，争取〔X 年〕以上。
- **递增**：年递增〔X%〕以内可接受，阶梯递增看总账。
- **免租期**：装修期免租至少〔X 天/月〕，写进合同。
- **转让费**：是否合理、是否有合法依据、能否分摊回收。

## 打分判级（阈值客户填）
| 总分 | 结论 | 动作 |
|---|---|---|
| ≥〔85〕 | 优质点位 | 走筹建流程，进 [[筹建开业Checklist]] |
| 〔70-84〕 | 合格点位 | 谈判优化条款/改造方案后复评 |
| 〔60-69〕 | 边际点位 | 需 DRI 评审，慎签 |
| <〔60〕 | 不合格 | PASS |

> 任何分数前置：**否决项 + 证照可办性先过**。这两关不过，打分结果一律作废。

## 用法
拓店第一步即用本卡逐点位打分横评，避免凭感觉签约。签约前最后一道闸是证照可办性。点位定下 → 交 [[筹建开业Checklist]] 启动筹建。

# 权限分级 · 四级

> 企业库和个人库最硬的区别。没有权限治理 = AI 资料垃圾场 + 隐私事故。

| 级别 | 含义 | 典型资产 | agent 行为 |
|---|---|---|---|
| 🟢 公开 | 可对外发布 | 对外物料、方法论、介绍 | 可写入对外产物 |
| 🟡 内部 | 团队内用 | 话术、SOP、运营数据 | 内部可用,不对外 |
| 🔴 受限 | 隐私/敏感 | 客户对话、通话记录、手机号、名单 | **绝不写入对外产物,只内部分析** |
| ⛔ 禁止入库 | 不该进库 | 证件、银行信息、未授权第三方资料 | 拒绝入库 |

## agent 红线
1. 🔴 受限资产 → 输出时必须脱敏/打码,绝不原文外发
2. 超标准的报价/优惠/对外承诺 → 必须人工确认
3. 不确定权限 → 默认按更高一级处理,问用户


## 治理 · 行业合规默认.md

# 餐饮（连锁）行业 · 合规与权限默认值

> 合成进成品库 `90-governance/行业合规默认.md`。客户可按自身情况收紧。
> ⚠️ 食品安全是餐饮的生命线。任何门店运营、供应链、出餐相关产出，动手前必读本页。各地市监/卫健细则可能更严，以当地《食品安全法》执行口径与监管要求为准。

## 默认权限分级（通用四级 + 餐饮补充）
| 资产类型 | 默认级别 |
|---|---|
| 顾客个人信息（姓名/手机/微信/地址/订单记录/会员数据）| 🔴 受限（永不对外，输出必脱敏）|
| 员工健康证/身份证/劳动合同/薪酬 | 🔴 受限（证件类敏感信息）|
| 供应商报价/进货价/毛利率/单店财务数据 | 🔴 受限（核心商业机密，决定生死）|
| 内部 SOP/出餐标准/服务话术/督导表/选址模型 | 🟡 内部 |
| 配方/中央厨房工艺/核心 Recipe | 🔴 受限（连锁命脉，分级授权，非定版不外传）|
| 对外菜单/品牌介绍/招商物料/门店海报 | 🟢 公开（须经合规审核，见红线）|
| 营业执照/食品经营许可证/排污许可等证照 | ⛔ 禁止入库（证件原件类，留原地建索引）|

## 餐饮行业红线（agent 必须遵守，对外/对内产出前逐条过）
1. **证照齐全才能营业**：门店必须持有效《营业执照》《食品经营许可证》方可经营；涉酒类、户外摆台等需对应许可。任何"新店开业/试营业"动作，先核证照状态，缺证 → 🔴 停止并人工确认，agent 不得拍板开业。
2. **员工持证上岗**：所有接触直接入口食品的从业人员必须持有效《健康证》方可上岗；健康证过期/缺失 → 该员工不得排班上岗。
3. **明厨亮灶**：后厨须符合明厨亮灶要求（透明厨房/视频公示/玻璃隔断等当地标准之一）；督导巡检必查。
4. **食材溯源可查**：进货须索证索票（供货方资质、检验检疫合格证明、进货台账），做到来源可追、去向可查。台账缺失 = 重大隐患。
5. **温度与保质期管控**：冷链不断链；冷藏/冷冻/热存温度达标；先进先出（FIFO）；过期、临期、变质食材一律禁用，立即报损隔离。
6. **留样制度**：按规定对每餐次成品留样并记录（通常 ≥125g、冷藏存 48 小时以上，以当地标准为准），供溯源。
7. **禁高危行为**：不得采购/使用来源不明食材、回收复用餐厨废弃油脂（地沟油）、超范围超量使用食品添加剂、销售过期/变质食品。命中任一 → 这是刑事/重罚级红线。
8. **过敏原与真实标注**：菜单成分、分量、产地、宣传不得虚假夸大；含已知过敏原/特殊配方应可向顾客说明，不得隐瞒。
9. **价格与计量诚信**：明码标价，不得价格欺诈、缺斤短两、强制消费。
10. **餐厨废弃物合规处置**：餐厨垃圾/废油交有资质单位回收并留台账，不得私自处置。

## agent 行为
- 任何涉及**出餐、采购验收、新店开业、对外宣传**的产出 → **先过上面红线**，命中食品安全/证照类 → 🔴 立即停止 + 人工确认，绝不自行放行。
- 涉及顾客个人信息、供应商报价、配方工艺 → 默认 🔴 受限，不写入任何对外产物，引用必脱敏。
- 不确定是否合规 → 默认按更严处理，问负责人。
- 食品安全事件（异物/食物中毒投诉/疑似变质）→ 走应急上报，第一时间隔离取证 + 通知 DRI，agent 不得擅自答复顾客承诺赔偿。

> 食品安全无小事。一次食安事故可能摧毁整个连锁品牌——对内对外都宁可保守、宁可停下来核实。
