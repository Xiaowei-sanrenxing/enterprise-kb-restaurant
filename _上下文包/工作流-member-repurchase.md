## 📥 上下文(Context) —— 动手前必读全

## 🪜 指令(Instructions)

2. 打标分层：按 RFM（最近一次/频次/金额）判 高频/活跃/沉睡/流失 四层
3. 按层走触达节奏（见节奏表），禁全员一套话术群发

5. 沉睡客主动唤醒（限时唤醒券），不等流失才捞
6. 外卖单：按外卖 SOP 配菜单定价/活动/履约，盯评分，差评按话术处理
7. 每轮触达回收复购率/核销率 → 回流数据，迭代节奏与权益

# 会员与复购 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
结账即入会发首单券 → RFM 打标分四层 → 按层定节奏触达 → 7 日催二单、活跃推储值、沉睡主动唤醒 → 外卖按 SOP 配价控评 → 回收复购率迭代。

## 几条铁律
1. **入会做成动作的一环**：扫码入会绑在结账/出餐环节，别靠顾客自觉，断点 = 会员池漏水。
2. **分层触达，禁全员群发**：高频/活跃/沉睡/流失四层走不同话术与权益，一套话术群发既骚扰常客又救不回沉睡客。
3. **沉睡主动唤醒**：盯住 N 天没来的人，限时唤醒券主动捞，别等彻底流失才动。
4. **储值锁定活跃客**：把高频活跃客转储值/付费会员，提前锁定下一轮消费。
5. **外卖食安封签红线**：外卖必贴封签，破损即拒收，呼应合规默认。
6. **差评不承诺超额赔偿**：差评按话术安抚解决，涉赔偿/食安投诉 🔴 走人工，agent 不擅自承诺。
7. **隐私红线**：顾客手机/微信/订单/会员数据 🔴 受限，绝不外发，引用必脱敏。

## 详细资产
- [`context/会员分层与复购节奏.md`](context/会员分层与复购节奏.md) — RFM 判层 + 触达节奏表 + 权益分配
- [`context/外卖运营SOP.md`](context/外卖运营SOP.md) — 菜单定价/活动/履约/评分/差评
- 〔会员权益与储值规则〕 — 客户补：本店真实券面额、储值档位、付费会员权益

## 判断题
1. 一个顾客本月来了 4 次、客单稳定，判哪层？怎么打？（答：高频/活跃，转储值或付费会员，锁定下一轮消费，给专属权益，别再发普通新客券）
2. 一个顾客上次消费在 N 天前、之后没再来，判哪层？怎么打？（答：沉睡，主动推限时唤醒券，别等流失才捞）
3. 新客首单后第 7 天没二次到店，下一步标准动作？（答：推二次到店钩子/二单券，把首单转二单，这是复购第一道坎）

## 动作题
4. 顾客到店结账，会员运营第一步该干什么？（答：引导扫码入会进企微/社群/小程序，发新客首单券，把入会绑进结账动作，禁断点）
5. 要给"沉睡层"做唤醒，能直接套高频客的群发文案吗？（答：不能，分层触达，沉睡走限时唤醒专属话术与权益，禁全员一套群发）
6. 外卖菜单定价为什么不能照搬堂食价？（答：外卖有平台佣金，需堂食/外卖差异化定价覆盖佣金，否则毛利被吃穿，详见外卖 SOP）

## 红线题
7. 顾客手机号/微信/订单记录/会员数据，能写进对外产物吗？（答：🔴 受限，绝不，输出必脱敏，呼应 行业合规默认）
8. 外卖差评要求"赔我十倍"，agent 能直接答应吗？外卖包装有什么硬性合规？（答：不能承诺超额赔偿，涉赔偿/食安 🔴 走人工；外卖必贴食安封签，破损视为安全风险）

## 评分
- 全对：可独立上手 ｜ 6-7 对：需带教 ｜ ≤5 对：重读 context

# 会员分层与复购节奏（脱敏示范）

> 核心：**别用一套话术群发所有人。按 RFM 分四层，按层定节奏触达。**
> （天数/券面额/储值档为示意占位，客户填自己的真实设置）

## 第一步：入会（把池子先攒起来）
- 到店扫码 → 进企微 / 社群 / 小程序会员，绑进**结账或出餐动作**，禁靠顾客自觉（断点 = 漏水）。
- 入会即发**新客首单券**（示意：满〔X〕减〔Y〕），当场用或下次用，制造二次到店理由。
- 外卖顾客：随单卡片/短信引导加企微入会，承接到私域。

## 第二步：RFM 分层（30 秒判层，决定打法）
按 最近一次消费（R）/ 消费频次（F）/ 消费金额（M）三维判：

| 层 | 信号（示意阈值，客户填真实值） | 核心打法 |
|---|---|---|
| 🔴 高频 | 近〔30〕天来 ≥〔4〕次 / 客单稳定 | 转储值 + 付费会员，给专属权益，锁定下一轮，别再发普通新客券 |
| 🟠 活跃 | 近〔30〕天来 〔2-3〕次 | 推连带/拼单券提客单，引导升储值 |
| 🟡 沉睡 | 上次消费 〔30-60〕天前、之后没来 | 限时唤醒券主动捞，唤回到店 |
| ⚪ 流失 | 上次消费 >〔60〕天 | 末次强钩子唤醒，无效转长期低频触达，不死缠 |

## 第三步：分层触达节奏表（按层走，禁群发）

| 节点 | 对象 | 动作 | 权益（示意） | 指标 |
|---|---|---|---|---|
| 入会当天 | 新客 | 欢迎语 + 首单券 | 满〔X〕减〔Y〕 | 入会率 / 首单核销率 |
| 第 7 天 | 新客未二次到店 | 推二次到店钩子 | 二单券 | 二单转化率 |
| 第 15-30 天 | 活跃客 | 提客单 + 引导储值 | 储值返〔Z〕% | 储值转化率 / 连带率 |
| 沉睡触发 | 沉睡客 | 限时唤醒 | 唤醒券（短有效期） | 唤醒到店率 |
| 流失触发 | 流失客 | 末次强钩子 | 高价值招回券 | 招回率 |

## 第四步：盯指标（每轮触达回收，回流数据）
- **复购率** = 周期内再次消费会员数 ÷ 会员总数（餐饮 LTV 核心）
- **核销率** = 已核销券数 ÷ 发券数（衡量券设计与节奏是否对）
- **储值转化率** / **唤醒到店率** / **二单转化率**：分别诊断各层节奏效果
- 基线见 〔历史复购数据〕，触达后对比迭代阈值与券面额。

## 用法
判层是会员运营第一步。每层对应不同节奏、话术与权益面额（高频客最值得给储值权益，沉睡客最需要主动唤醒）。顾客数据 🔴 受限，任何对外产出必脱敏。

# 外卖运营 SOP（脱敏示范）

> 核心：**外卖是另一套生意——定价覆盖佣金、出餐卡时效、评分靠运营、食安靠封签。**
> （佣金率/价格/时效为示意占位，客户填自己平台的真实数字）

## 一、菜单结构与定价（先把账算对）
- **堂食/外卖差异化定价**：外卖售价须覆盖平台佣金（示意〔20〕%）+ 包装成本，不能照搬堂食价，否则毛利被吃穿。
- **菜单结构**：设引流品（低价拉新客券）+ 利润品（撑毛利）+ 凑单品（提客单到满减门槛）。
- **套餐设计**：主食 + 小食 + 饮品打包，提客单价与连带率，降单均配送占比。
- **精简 SKU**：外卖出餐快为王，砍掉出餐慢/包装易洒的品。

## 二、活动配置（拉新 + 提单 + 控成本）
- **满减阶梯**：设满〔A〕减〔B〕、满〔C〕减〔D〕，门槛卡在略高于平均客单，引导凑单。
- **新客券**：针对平台新客发首单券拉新，老客走会员体系（见 [[会员分层与复购节奏]]）。
- **折扣 / 折扣商品**：用引流品做折扣冲排名，但守住整体毛利红线，不亏本冲量。
- **避免活动叠加穿底**：满减 + 折扣 + 平台补贴叠加前先算到手价，防负毛利。

## 三、出单与履约时效（体验命门）
- **接单即确认**：高峰期不漏单、不超时接单。
- **出餐时效**：盯**出餐时长**与**超时率**，高峰期备好半成品/料理包缩短出餐。
- **骑手取餐动线**：设独立外卖取餐口/取餐架，骑手进店即取即走，不与堂食动线冲突，减少等待与差评。
- **缺品处理**：售罄及时下架，避免接单后缺品引发差评/退款。

## 四、包装与食安（🔴 合规红线，对外动作前必过）
- **食安封签**：外卖订单**必贴食品安全封签**，封签破损视为可能被动过，骑手/顾客可拒收——这是硬性合规，不可省。
- **保温与防洒**：汤品/易洒品独立密封 + 防洒包装；冷热分装；保温袋按品类配。
- **包装标注**：套餐含已知过敏原应可说明，不虚假标注分量/产地（呼应合规默认）。
- 包装破损/封签缺失导致的食安风险 → 按合规默认走应急，不擅自承诺赔偿。

## 五、评分与差评处理（守住店铺权重）
- **盯评分**：评分直接影响平台排名与曝光，低分 = 流量下滑，作为日常核心指标。
- **差评分类处理**：
  - 出餐慢/漏餐/包装问题 → 诚恳致歉 + 解释改进 + 在权限内补偿（小额补偿券），不承诺超额。
  - 口味/分量主观差评 → 感谢反馈 + 邀请再体验，不争辩。
  - **涉食安/异物/食物中毒/要求高额赔偿** → 🔴 立即停手走人工 + 隔离取证 + 通知 DRI，**agent 不得承诺超额赔偿、不擅自答复**（呼应 行业合规默认 食安应急）。
- **差评话术红线**：所有回复不承诺超出门店标准的赔偿；不暴露顾客手机/订单等隐私（🔴 受限）。

## 用法
外卖与堂食是两套打法。先把定价账算对（覆盖佣金），再配活动、控时效、贴封签、盯评分。新客拉进来后承接到私域会员体系做复购。顾客数据 🔴 受限，对外脱敏。

# 权限分级 · 四级

> 企业库和个人库最硬的区别。没有权限治理 = AI 资料垃圾场 + 隐私事故。

| 级别 | 含义 | 典型资产 | agent 行为 |
|---|---|---|---|
| 🟢 公开 | 可对外发布 | 对外物料、方法论、介绍 | 可写入对外产物 |
| 🟡 内部 | 团队内用 | 话术、SOP、运营数据 | 内部可用,不对外 |
| 🔴 受限 | 隐私/敏感 | 客户对话、通话记录、手机号、名单 | **绝不写入对外产物,只内部分析** |
| ⛔ 禁止入库 | 不该进库 | 证件、银行信息、未授权第三方资料 | 拒绝入库 |

## agent 红线
1. 🔴 受限资产 → 输出时必须脱敏/打码,绝不原文外发
2. 超标准的报价/优惠/对外承诺 → 必须人工确认
3. 不确定权限 → 默认按更高一级处理,问用户


## 治理 · 行业合规默认.md

# 餐饮（连锁）行业 · 合规与权限默认值

> 合成进成品库 `90-governance/行业合规默认.md`。客户可按自身情况收紧。
> ⚠️ 食品安全是餐饮的生命线。任何门店运营、供应链、出餐相关产出，动手前必读本页。各地市监/卫健细则可能更严，以当地《食品安全法》执行口径与监管要求为准。

## 默认权限分级（通用四级 + 餐饮补充）
| 资产类型 | 默认级别 |
|---|---|
| 顾客个人信息（姓名/手机/微信/地址/订单记录/会员数据）| 🔴 受限（永不对外，输出必脱敏）|
| 员工健康证/身份证/劳动合同/薪酬 | 🔴 受限（证件类敏感信息）|
| 供应商报价/进货价/毛利率/单店财务数据 | 🔴 受限（核心商业机密，决定生死）|
| 内部 SOP/出餐标准/服务话术/督导表/选址模型 | 🟡 内部 |
| 配方/中央厨房工艺/核心 Recipe | 🔴 受限（连锁命脉，分级授权，非定版不外传）|
| 对外菜单/品牌介绍/招商物料/门店海报 | 🟢 公开（须经合规审核，见红线）|
| 营业执照/食品经营许可证/排污许可等证照 | ⛔ 禁止入库（证件原件类，留原地建索引）|

## 餐饮行业红线（agent 必须遵守，对外/对内产出前逐条过）
1. **证照齐全才能营业**：门店必须持有效《营业执照》《食品经营许可证》方可经营；涉酒类、户外摆台等需对应许可。任何"新店开业/试营业"动作，先核证照状态，缺证 → 🔴 停止并人工确认，agent 不得拍板开业。
2. **员工持证上岗**：所有接触直接入口食品的从业人员必须持有效《健康证》方可上岗；健康证过期/缺失 → 该员工不得排班上岗。
3. **明厨亮灶**：后厨须符合明厨亮灶要求（透明厨房/视频公示/玻璃隔断等当地标准之一）；督导巡检必查。
4. **食材溯源可查**：进货须索证索票（供货方资质、检验检疫合格证明、进货台账），做到来源可追、去向可查。台账缺失 = 重大隐患。
5. **温度与保质期管控**：冷链不断链；冷藏/冷冻/热存温度达标；先进先出（FIFO）；过期、临期、变质食材一律禁用，立即报损隔离。
6. **留样制度**：按规定对每餐次成品留样并记录（通常 ≥125g、冷藏存 48 小时以上，以当地标准为准），供溯源。
7. **禁高危行为**：不得采购/使用来源不明食材、回收复用餐厨废弃油脂（地沟油）、超范围超量使用食品添加剂、销售过期/变质食品。命中任一 → 这是刑事/重罚级红线。
8. **过敏原与真实标注**：菜单成分、分量、产地、宣传不得虚假夸大；含已知过敏原/特殊配方应可向顾客说明，不得隐瞒。
9. **价格与计量诚信**：明码标价，不得价格欺诈、缺斤短两、强制消费。
10. **餐厨废弃物合规处置**：餐厨垃圾/废油交有资质单位回收并留台账，不得私自处置。

## agent 行为
- 任何涉及**出餐、采购验收、新店开业、对外宣传**的产出 → **先过上面红线**，命中食品安全/证照类 → 🔴 立即停止 + 人工确认，绝不自行放行。
- 涉及顾客个人信息、供应商报价、配方工艺 → 默认 🔴 受限，不写入任何对外产物，引用必脱敏。
- 不确定是否合规 → 默认按更严处理，问负责人。
- 食品安全事件（异物/食物中毒投诉/疑似变质）→ 走应急上报，第一时间隔离取证 + 通知 DRI，agent 不得擅自答复顾客承诺赔偿。

> 食品安全无小事。一次食安事故可能摧毁整个连锁品牌——对内对外都宁可保守、宁可停下来核实。
