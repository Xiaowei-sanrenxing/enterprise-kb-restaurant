1. **新店复制类任务**：

   2.4 出问题清单 → 限期整改 → 复查 → 回流总部台账(闭环,不止于打分)

# 连锁标准化与督导 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
**标准化**：把样板店全套标准打包成"开店包" → 复刻到新店 → 督导验收过关才转正。
**督导**：拉巡检表逐维度打分 → 一票否决项零容忍 → 问题限期整改 → 复查 → 回流总部(闭环)。

## 几条铁律
1. **SOP 可复制性 = 连锁命根**：标准只在老师傅脑子里 = 开不了第二家好店。一切靠手口传 → 必须沉淀成开店包。
2. **开店包七件套必须齐**：SKU 配方卡 / 设备清单 / 动线布局图 / 岗位编制排班模板 / 培训手册 / 物料清单 / 开业 SOP。缺一件,新店复制就会走样。
3. **督导不止打分,必须闭环**：发现问题 → 限期整改 → 复查 → 回流总部台账。只打分不复查 = 督导白做。
4. **飞检照真实状态**：例行巡店容易"作秀",不提前通知的飞行检查才能查出真实运营。
5. **食安/证照/健康证一票否决**：命中任一 → 直接红牌,不论其他维度多高分;新店缺证 🔴 不得开业(呼应 [`../../90-governance/行业合规默认.md`](../../90-governance/行业合规默认.md))。
6. **配方红线**：配方/央厨工艺 🔴 受限,分级授权,非定版不外传。

## 新店复制时间线（人话版）
筹建(场地/证照/设备进场) → 培训带教(照培训手册练到达标) → 试营业压测(高峰出餐/动线跑通) → 督导验收(逐维度过关 + 食安证照核查) → 转正运营(进常态督导)。

## 详细资产
- [`context/新店复制流程.md`](context/新店复制流程.md) — 开店包七件套 + 复制时间线 + 成功标准
- [`context/督导巡检表.md`](context/督导巡检表.md) — 可直接用的分维度巡检表 + 飞检 + 整改闭环
- 〔样板店开店包母版〕 — 客户补:本品牌的标准范本

## 判断题
1. 新店要开业,开店包里只有培训手册和物料清单,缺配方卡和动线图 → 能进入复制流程吗?（答：不能。开店包七件套必须齐——SKU 配方卡/设备清单/动线布局图/排班模板/培训手册/物料清单/开业 SOP,缺一件就会走样,标记不可开。）
2. 督导巡检某店：服务、5S、出品都打了高分,但发现 2 名后厨员工健康证过期 → 这店巡检算合格吗?（答：不合格,直接红牌。健康证是一票否决项,不论其他维度多高分。）
3. "例行巡店"和"飞行检查(飞检)"有什么本质区别?为什么要飞检?（答：例行巡店提前通知、门店容易临时作秀;飞检不通知、查的是真实运营状态。靠飞检才能发现日常真问题。）
4. 新店试营业各项都顺,但《食品经营许可证》还在办理中 → 督导能判定"通过验收、可转正运营"吗?（答：不能。证照是一票否决项,缺证 🔴 停止 + 人工确认,agent 不得拍板开业/转正。）

7. 新店复制时间线的五个阶段按顺序是?转正前必过哪一关?（答：筹建 → 培训带教 → 试营业压测 → 督导验收 → 转正运营;转正前必过督导验收 + 食安证照核查。）

# 招商加盟合规处置（操作 SOP）

> 补盲区：库原无加盟业务线，但连锁品牌高频开放加盟。本卡管"加盟时配方/财务怎么给、招商怎么宣传才合规"，加盟咨询归本工作流（连锁标准化的自然延伸）。
> 核心：加盟可以做，但**命脉资产分级授权、商业机密不外泄、招商宣传不踩虚假承诺**。

## 给加盟商什么、怎么给（分级授权）
| 资产 | 默认权限 | 给加盟商的方式 |
|---|---|---|
| 配方卡/中央厨房工艺 | 🔴 受限（连锁命脉）| **绝不打包原文外发**；签约 + 保密协议后，以运营手册/标准化形式分级授权 |
| 进货价/单店真实财务/底价 | 🔴 核心商业机密 | **永不对外**；对加盟商只展示**脱敏的成本结构示意/盈利模型**，非真实底价 |
| 招商手册/样板店展示 | 🟢 对外（须合规审核）| 可给，但须经合规审核、内容真实不夸大 |

## 招商宣传红线（招商手册/话术）
- 🔴 禁收益保证：不得写"稳赚/X 个月回本/保证盈利/包成功"等承诺（涉虚假宣传/欺诈）。
- 收益须用"参考/因经营而异"口径，不与个别样板店挂钩误导。
- 须依法做**商业特许经营信息披露**；具备"两店一年"等特许经营条件并按规备案（《商业特许经营管理条例》）。

## agent 标准动作
1. 加盟咨询/招商内容 → 走本卡，不绕过。
2. 有人要"配方卡+财务打包发加盟商" → **拒绝原文外发**，改走"签保密协议 + 分级授权运营手册 + 脱敏盈利模型"，转招商/法务。
3. 招商文案出现收益保证/回本承诺 → 拦截改稿，去保证性表述。
4. 加盟合同/信息披露 → 必须法务 + 人工确认，agent 不自拟。

## 标准话术（老板要打包配方+财务给加盟商时）
"配方和单店真实财务是咱们的命脉和商业机密，不能原文打包外发。合规做法：加盟商签保密协议后，给标准化运营手册（不是配方原文）+ 脱敏的盈利模型示意，具体条款我转招商负责人和法务。"

| 件 | 内容 | 解决的问题 |
|---|---|---|
| ① SKU 与配方卡 🔴 | 每道菜的用料、克重、工艺步骤、出品标准图 | 出品一致性（同一个味道）|
| ② 设备清单 | 设备型号/数量/摆位/采购或租赁来源 | 后厨产能与复刻一致 |
| ③ 动线布局图 | 前厅+后厨平面图、动线走向、工位分布 | 高峰不堵、效率可复制 |
| ④ 岗位编制与排班模板 | 各岗人数、班次、高峰加排规则 | 人效达标、不缺岗不冗员 |
| ⑤ 培训手册 | 各岗操作 SOP、考核点、带教节奏 | 新人练到达标的依据 |
| ⑥ 物料清单 | 食材/包材/易耗品 SKU + 首批进货量 | 开业不断货、不囤货 |
| ⑦ 开业 SOP | 开业前 N 天倒排清单、试营业脚本、开业当天流程 | 开业不手忙脚乱 |

> ⚠️ 配方卡（①）属 🔴 受限,分级授权、非定版不外传,引用必脱敏。开店包不齐 → 标记**不可开**,不得进入复制流程。

## 第二步：新店复制时间线（五阶段倒排）

```
筹建            场地交付 / 证照办理(营业执照+食品经营许可证) / 设备进场调试 / 首批物料到位
  ↓
培训带教        照培训手册练 → 各岗考核达标 → 后厨配方卡练到出品一致
  ↓
试营业压测      高峰出餐压测 / 动线跑通 / 出餐时长达标 / 试营业脚本走一遍
  ↓
督导验收 ★关卡   按督导巡检表逐维度过关 + 食安证照健康证核查(一票否决)
  ↓
转正运营        进入常态督导节奏,纳入例行巡店+飞检
```

> 督导验收是**硬关卡**：不过关不转正。食安/证照/健康证命中 🔴 → 停止 + 人工确认,agent 不得判定可开业。

## 第三步：复制成功标准（验收看这三条）

| 维度 | 标准 |
|---|---|
| 出品一致性 | 与样板店出品对照,达标率 ≥〔占位 %〕 |
| SOP 落地率 | 培训手册各岗 SOP 实操达标率 ≥〔占位 %〕 |
| 首月达标线 | 首月翻台率/客单价/食材成本率达〔占位线〕 |

## 用法
新店复制第一步永远是核开店包七件套是否齐全(缺项不可开),再按时间线推进,转正前必过督导验收。复制中暴露的"哪个标准没落地" → 回流补全开店包母版（见 [[督导巡检表]] 的整改闭环）。

# 督导巡检表（脱敏示范，可直接用）

> 核心：**督导不止打分,必须闭环——发现问题 → 限期整改 → 复查 → 回流总部。只打分不复查 = 督导白做。**
> 食安/证照/健康证为**一票否决项**,命中直接红牌,不论总分（呼应 [[行业合规默认]]）。
> （权重/分值/红黄牌线为占位,客户按品牌标准填。）

## 一、分维度巡检打分项（逐项打分）

| # | 维度 | 主要检查项（agent 逐项核） | 否决? |
|---|---|---|---|
| 1 | **食品安全与卫生** | 明厨亮灶到位 / 留样合规 / 食材无过期变质 / 无地沟油等高危行为 / 索证索票台账齐 | 🔴 一票否决 |
| 2 | **证照与健康证** | 营业执照+食品经营许可证有效悬挂 / 全员健康证有效 / 涉酒等许可齐 | 🔴 一票否决 |
| 3 | **库存与效期** | FIFO 先进先出 / 临期效期标识 / 冷链温度达标 / 报损隔离规范 / 账实相符 | 命中变质即转 1 |
| 4 | **出品一致性** | 配方卡用料克重达标 / 出餐时长达标 / 出品对照样板店达标率 / 摆盘标准 | 打分项 |
| 5 | **服务标准** | 接待话术 / 响应速度 / 投诉处理 / 着装仪容 | 打分项 |
| 6 | **现场 5S** | 整理/整顿/清扫/清洁/素养 / 设备保养 / 工位整洁 | 打分项 |
| 7 | **营销执行** | 当期活动物料到位 / 券核销规范 / 价格明码标价无欺诈 | 打分项 |

> 评分：维度 1、2 为一票否决,命中任一 → **直接红牌**,不论其他维度多高分;agent 不得判定门店"巡检合格"。

## 二、飞行检查（飞检）机制

- **为什么飞检**：例行巡店提前通知,门店易临时作秀;**飞检不通知,查的是真实运营状态**。
- **怎么飞**：不预告时间、随机选店、直奔后厨与效期区(最易出问题的地方)。
- **频次**：〔占位：每店每季 ≥N 次〕,问题店加密。

## 三、评分与红黄牌处置

| 结果 | 触发条件（占位线） | 处置 |
|---|---|---|
| 🟢 绿牌 | 总分 ≥〔占位〕且无否决项 | 通过,常态督导 |
| 🟡 黄牌 | 总分〔占位区间〕或有非否决类问题 | 限期整改 + 复查 |
| 🔴 红牌 | 命中食安/证照/健康证否决项,或总分 <〔占位〕 | 立即处置 + 人工确认升级,严重者停业整顿 |

## 四、整改闭环（督导的命根，不止于打分）

```
发现问题        巡检/飞检逐项记录,列问题清单(分维度+严重度)
  ↓
限期整改        下整改单,定责任人+整改期限
  ↓
复查            到期复查,核实是否真改(否决项必现场复查,不接受口头)
  ↓
回流总部        整改结果回流总部台账 → 反复出现的问题回流开店包/培训手册母版迭代
```

## 用法
拉表 → 选类型(例行/飞检)→ 逐维度打分 → 否决项零容忍 → 出问题清单 → 走整改闭环。反复出现的问题不只是单店整改,要回流总部把标准补进 [[新店复制流程]] 的开店包,从源头杜绝。

# 权限分级 · 四级

> 企业库和个人库最硬的区别。没有权限治理 = AI 资料垃圾场 + 隐私事故。

| 级别 | 含义 | 典型资产 | agent 行为 |
|---|---|---|---|
| 🟢 公开 | 可对外发布 | 对外物料、方法论、介绍 | 可写入对外产物 |
| 🟡 内部 | 团队内用 | 话术、SOP、运营数据 | 内部可用,不对外 |
| 🔴 受限 | 隐私/敏感 | 客户对话、通话记录、手机号、名单 | **绝不写入对外产物,只内部分析** |
| ⛔ 禁止入库 | 不该进库 | 证件、银行信息、未授权第三方资料 | 拒绝入库 |

## agent 红线
1. 🔴 受限资产 → 输出时必须脱敏/打码,绝不原文外发
2. 超标准的报价/优惠/对外承诺 → 必须人工确认
3. 不确定权限 → 默认按更高一级处理,问用户


## 治理 · 行业合规默认.md

# 餐饮（连锁）行业 · 合规与权限默认值

> 合成进成品库 `90-governance/行业合规默认.md`。客户可按自身情况收紧。
> ⚠️ 食品安全是餐饮的生命线。任何门店运营、供应链、出餐相关产出，动手前必读本页。各地市监/卫健细则可能更严，以当地《食品安全法》执行口径与监管要求为准。

## 默认权限分级（通用四级 + 餐饮补充）
| 资产类型 | 默认级别 |
|---|---|
| 顾客个人信息（姓名/手机/微信/地址/订单记录/会员数据）| 🔴 受限（永不对外，输出必脱敏）|
| 员工健康证/身份证/劳动合同/薪酬 | 🔴 受限（证件类敏感信息）|
| 供应商报价/进货价/毛利率/单店财务数据 | 🔴 受限（核心商业机密，决定生死）|
| 内部 SOP/出餐标准/服务话术/督导表/选址模型 | 🟡 内部 |
| 配方/中央厨房工艺/核心 Recipe | 🔴 受限（连锁命脉，分级授权，非定版不外传）|
| 对外菜单/品牌介绍/招商物料/门店海报 | 🟢 公开（须经合规审核，见红线）|
| 营业执照/食品经营许可证/排污许可等证照 | ⛔ 禁止入库（证件原件类，留原地建索引）|

## 餐饮行业红线（agent 必须遵守，对外/对内产出前逐条过）
1. **证照齐全才能营业**：门店必须持有效《营业执照》《食品经营许可证》方可经营；涉酒类、户外摆台等需对应许可。任何"新店开业/试营业"动作，先核证照状态，缺证 → 🔴 停止并人工确认，agent 不得拍板开业。
2. **员工持证上岗**：所有接触直接入口食品的从业人员必须持有效《健康证》方可上岗；健康证过期/缺失 → 该员工不得排班上岗。
3. **明厨亮灶**：后厨须符合明厨亮灶要求（透明厨房/视频公示/玻璃隔断等当地标准之一）；督导巡检必查。
4. **食材溯源可查**：进货须索证索票（供货方资质、检验检疫合格证明、进货台账），做到来源可追、去向可查。台账缺失 = 重大隐患。
5. **温度与保质期管控**：冷链不断链；冷藏/冷冻/热存温度达标；先进先出（FIFO）；过期、临期、变质食材一律禁用，立即报损隔离。
6. **留样制度**：按规定对每餐次成品留样并记录（通常 ≥125g、冷藏存 48 小时以上，以当地标准为准），供溯源。
7. **禁高危行为**：不得采购/使用来源不明食材、回收复用餐厨废弃油脂（地沟油）、超范围超量使用食品添加剂、销售过期/变质食品。命中任一 → 这是刑事/重罚级红线。
8. **过敏原与真实标注**：菜单成分、分量、产地、宣传不得虚假夸大；含已知过敏原/特殊配方应可向顾客说明，不得隐瞒。
9. **价格与计量诚信**：明码标价，不得价格欺诈、缺斤短两、强制消费。
10. **餐厨废弃物合规处置**：餐厨垃圾/废油交有资质单位回收并留台账，不得私自处置。

## agent 行为
- 任何涉及**出餐、采购验收、新店开业、对外宣传**的产出 → **先过上面红线**，命中食品安全/证照类 → 🔴 立即停止 + 人工确认，绝不自行放行。
- 涉及顾客个人信息、供应商报价、配方工艺 → 默认 🔴 受限，不写入任何对外产物，引用必脱敏。
- 不确定是否合规 → 默认按更严处理，问负责人。
- 食品安全事件（异物/食物中毒投诉/疑似变质）→ 走应急上报，第一时间隔离取证 + 通知 DRI，agent 不得擅自答复顾客承诺赔偿。

> 食品安全无小事。一次食安事故可能摧毁整个连锁品牌——对内对外都宁可保守、宁可停下来核实。
