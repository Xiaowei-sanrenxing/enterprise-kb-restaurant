## 🪜 指令（Instructions）
1. **采购前**：核供应商资质（索证索票齐不齐）→ 比价定点 → 按销量预测/库存下单（防积压防断货）
2. **到货时**：按验收标准逐项查——数量 / 质量 / 温度（冷链）/ 保质期 / 检验检疫证明

# 供应链与采购 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
核供应商资质比价定点 → 按预测下单 → 到货过 5 项验收 → 不合格拒收留证 → 合格入台账按 FIFO 上架 → 冷链不断链 → 算成本率 → 超标走排查清单归因整改。

## 两条命脉
**命脉一：成本率守住**——食材成本率是餐饮命门，目标区间〔30%~40%占位〕。超标四大归因：采购涨价、损耗、出品分量失控、盗损。靠标准 Recipe 卡控分量、菜单工程（高毛利爆品搭配）抬整体毛利。
**命脉二：食品安全不出事**——索证索票、进货台账、冷链不断链、拒收变质，是不可逾越的合规红线（见 [`../../90-governance/行业合规默认.md`](../../90-governance/行业合规默认.md)）。

## 几条铁律
1. **索证索票齐才下单**：供货资质 + 检验检疫合格证明缺一不可，缺证不进货。
2. **到货必验五项**：数量 / 质量 / 温度 / 保质期 / 检疫证明，一项不合格即拒收，不入库不上账。
3. **每笔进货上台账**：来源可追、去向可查，台账缺失 = 重大隐患。
4. **冷链不断链 + FIFO**：温度全程达标，先进先出，临期过期立即报损隔离。
5. **成本超标必归因**：不是只看数字红了，要定位到底是涨价、损耗、分量还是盗损。
6. **数字红线**：供应商报价 / 进货价 / 毛利率 🔴 受限，绝不外发，引用必脱敏。

## 详细资产
- [`context/食材成本控制法.md`](context/食材成本控制法.md) — 成本率公式 + 超标排查清单 + 标准 Recipe 卡控成本
- [`context/采购验收与溯源SOP.md`](context/采购验收与溯源SOP.md) — 供应商管理 + 5 项验收 + 拒收流程 + 台账溯源
- 〔供应商档案/比价表〕 — 客户补：定点供应商资质与报价（🔴 受限）
- 〔标准 Recipe 卡库〕 — 客户补：每道菜标准分量与成本基准

# 采购验收与溯源 SOP

> 从供应商到入库的标准动作。**索证索票、进货台账、冷链不断链是食安合规红线**（呼应 [行业合规默认](../../../90-governance/行业合规默认.md)），一项不漏。
> （报价/进货价 🔴 受限，对外引用必脱敏。）

## 一、供应商管理（采购前）
1. **索证索票**：每家供货方必须提供——供货资质（营业执照、食品经营/生产许可证）、随货检验检疫合格证明 / 检测报告。缺证 → 不下单。
2. **供货资质留档**：资质入〔供应商档案〕，定期复核有效期，过期前预警换证。
3. **比价定点**：同品类多家比价，择优定点；价格只是一项，资质与稳定供货同等重要。更换主力供应商需人工确认。

## 二、下单（采购）
- 按销量预测 + 当前库存下单，防积压（增损耗）也防断货（影响出餐）。
- 高周转/易损食材小批勤进；耐储食材按 FIFO 备货。

## 三、到货验收（五项必查，逐项过）
| 项 | 标准 | 不合格处理 |
|---|---|---|
| **数量** | 与订单一致，过磅核重 | 短缺/超量 → 记录，按合同处理 |
| **质量** | 新鲜、无变质腐败、无异物异味、规格达标 | 变质/异常 → 拒收 |
| **温度** | 冷藏/冷冻达标，无解冻复冻痕迹 | 温度超标/断链 → 拒收 |
| **保质期** | 在保质期内且余期充足，无临期混入 | 过期/临期不符 → 拒收 |
| **检验检疫证明** | 随货证明齐全、与货物对应 | 缺证/不符 → 拒收 |

## 四、不合格拒收流程
1. 当场判定不合格 → **不入库、不上台账**。
2. 拍照留证（货物状态 + 温度 + 证明缺失情况）。
3. 通知〔供应商 DRI〕，按合同退换/索赔，记录到供应商档案。
4. **绝不因供应商催促或"赶时间"放行**——温度断链/变质/缺证是食安红线，命中即 🔴 停止 + 人工确认。
5. 同一供应商高频拒收 → 进黑名单复核，回流自我进化接口。

## 五、进货台账与溯源
- 每笔合格进货登记台账：**供货方、品名、规格、数量、进货日期、保质期、检验检疫证明编号、经手人**。
- 做到**来源可追、去向可查**——出问题能反查到批次和供应商。台账缺失 = 重大隐患。
- 配合留样制度（成品按规定留样，见合规默认），形成完整溯源链。

## 六、入库（冷链不断链 + FIFO）
1. 合格食材验收后**第一时间入对应温区**，缩短常温暴露时间，冷链全程不断链。
2. 冷藏 / 冷冻 / 热存温度达标，定时记录温度。
3. **FIFO 先进先出**上架：新货放后/下，旧货放前/上，防过期。
4. 临期食材标识优先消化或报损隔离；过期变质立即报损隔离禁用。

# 食材成本控制法

> 食材成本率（Food Cost）是餐饮第一命门。这页教 agent：怎么算、超标怎么逐项归因、怎么用标准化把成本摁住。
> （所有率值/单价/毛利为示意，客户填自己公司的真实红线数字。报价/进货价/毛利率 🔴 受限。）

## 一、食材成本率怎么算
```
食材成本率 = 实际耗用食材成本 ÷ 同期营业额 × 100%
实际耗用食材成本 = 期初库存 + 本期进货 − 期末库存
```
- 目标区间：〔30%~40%占位〕，以本店定版红线为准（品类不同区间不同）。
- 算之前先盘点：账面与实物对得上，算出来的率才可信。账实不符本身就是信号（损耗/盗损）。

## 二、超标预警与四大归因
率红了不是直接换料提价，先定位原因。四大来源：

| 归因 | 信号 | 整改方向 |
|---|---|---|
| **采购涨价** | 进货价上行、比价表显示供应商提价 | 重新比价/换定点供应商（需人工确认）/调整菜单或分量 |
| **损耗** | 报损量↑、临期过期增多、加工出成率低 | 查 FIFO 执行、冷链温度、加工标准；改进储存与排产 |
| **出品分量失控** | 单品成本异常高、出品忽大忽小 | 回推标准 Recipe 卡，按标准分量重新培训出品 |
| **盗损** | 盘点账实长期不符、库存莫名减少 | 查权限/监控/盘点频次，收紧出入库管理 |

## 三、成本率异常排查清单（agent 可直接照着跑）
1. **先盘点核账**：期初+进货−期末 与系统是否一致？账实不符 → 怀疑损耗/盗损。
2. **查进货价**：对比上期比价表，进货价有没有涨？涨了多少？→ 采购涨价。
3. **查报损/损耗**：报损率是否上升？临期过期是否增多？出成率是否下降？→ 损耗。
4. **查单品成本**：哪个菜的成本率异常？该菜出品分量是否对得上标准 Recipe 卡？→ 分量失控。
5. **查出入库与盘点缺口**：库存有没有对不上账的莫名减少？→ 盗损。
6. **定位后给整改 + 监控复发**：每条异常记录归因 + 整改动作，回流自我进化接口。

## 四、用标准化把成本摁住
- **标准 Recipe 卡控分量**：每道菜定死食材种类、克重、出成，这是分量不失控、成本可算的基准。央厨净菜/半成品更要按卡。
- **报损管理**：变质/过期/操作失误的损失要日清记录、归因，损耗不是"自然现象"是可管的。临期食材按规则优先消化或报损隔离，不得继续用变质品（食安红线）。
- **菜单工程（高毛利爆品搭配）**：把菜品按"毛利高低 × 点击率高低"分四象限——
  - 高毛利高人气＝明星品，重点推、放显眼位；
  - 高毛利低人气＝潜力品，靠搭配/话术带；
  - 低毛利高人气＝引流品，控量或微调分量/定价；
  - 低毛利低人气＝拖累品，考虑下架。
  通过菜单结构而非单纯压价来抬整体毛利。（毛利率属 🔴 受限，对外不披露具体数字。）

# 权限分级 · 四级

> 企业库和个人库最硬的区别。没有权限治理 = AI 资料垃圾场 + 隐私事故。

| 级别 | 含义 | 典型资产 | agent 行为 |
|---|---|---|---|
| 🟢 公开 | 可对外发布 | 对外物料、方法论、介绍 | 可写入对外产物 |
| 🟡 内部 | 团队内用 | 话术、SOP、运营数据 | 内部可用,不对外 |
| 🔴 受限 | 隐私/敏感 | 客户对话、通话记录、手机号、名单 | **绝不写入对外产物,只内部分析** |
| ⛔ 禁止入库 | 不该进库 | 证件、银行信息、未授权第三方资料 | 拒绝入库 |

## agent 红线
1. 🔴 受限资产 → 输出时必须脱敏/打码,绝不原文外发
2. 超标准的报价/优惠/对外承诺 → 必须人工确认
3. 不确定权限 → 默认按更高一级处理,问用户

# 餐饮（连锁）行业 · 合规与权限默认值

> 合成进成品库 `90-governance/行业合规默认.md`。客户可按自身情况收紧。
> ⚠️ 食品安全是餐饮的生命线。任何门店运营、供应链、出餐相关产出，动手前必读本页。各地市监/卫健细则可能更严，以当地《食品安全法》执行口径与监管要求为准。

## 默认权限分级（通用四级 + 餐饮补充）
| 资产类型 | 默认级别 |
|---|---|
| 顾客个人信息（姓名/手机/微信/地址/订单记录/会员数据）| 🔴 受限（永不对外，输出必脱敏）|
| 员工健康证/身份证/劳动合同/薪酬 | 🔴 受限（证件类敏感信息）|
| 供应商报价/进货价/毛利率/单店财务数据 | 🔴 受限（核心商业机密，决定生死）|
| 内部 SOP/出餐标准/服务话术/督导表/选址模型 | 🟡 内部 |
| 配方/中央厨房工艺/核心 Recipe | 🔴 受限（连锁命脉，分级授权，非定版不外传）|
| 对外菜单/品牌介绍/招商物料/门店海报 | 🟢 公开（须经合规审核，见红线）|
| 营业执照/食品经营许可证/排污许可等证照 | ⛔ 禁止入库（证件原件类，留原地建索引）|

## 餐饮行业红线（agent 必须遵守，对外/对内产出前逐条过）
1. **证照齐全才能营业**：门店必须持有效《营业执照》《食品经营许可证》方可经营；涉酒类、户外摆台等需对应许可。任何"新店开业/试营业"动作，先核证照状态，缺证 → 🔴 停止并人工确认，agent 不得拍板开业。
2. **员工持证上岗**：所有接触直接入口食品的从业人员必须持有效《健康证》方可上岗；健康证过期/缺失 → 该员工不得排班上岗。
3. **明厨亮灶**：后厨须符合明厨亮灶要求（透明厨房/视频公示/玻璃隔断等当地标准之一）；督导巡检必查。
4. **食材溯源可查**：进货须索证索票（供货方资质、检验检疫合格证明、进货台账），做到来源可追、去向可查。台账缺失 = 重大隐患。
5. **温度与保质期管控**：冷链不断链；冷藏/冷冻/热存温度达标；先进先出（FIFO）；过期、临期、变质食材一律禁用，立即报损隔离。
6. **留样制度**：按规定对每餐次成品留样并记录（通常 ≥125g、冷藏存 48 小时以上，以当地标准为准），供溯源。
7. **禁高危行为**：不得采购/使用来源不明食材、回收复用餐厨废弃油脂（地沟油）、超范围超量使用食品添加剂、销售过期/变质食品。命中任一 → 这是刑事/重罚级红线。
8. **过敏原与真实标注**：菜单成分、分量、产地、宣传不得虚假夸大；含已知过敏原/特殊配方应可向顾客说明，不得隐瞒。
9. **价格与计量诚信**：明码标价，不得价格欺诈、缺斤短两、强制消费。
10. **餐厨废弃物合规处置**：餐厨垃圾/废油交有资质单位回收并留台账，不得私自处置。

## agent 行为
- 任何涉及**出餐、采购验收、新店开业、对外宣传**的产出 → **先过上面红线**，命中食品安全/证照类 → 🔴 立即停止 + 人工确认，绝不自行放行。
- 涉及顾客个人信息、供应商报价、配方工艺 → 默认 🔴 受限，不写入任何对外产物，引用必脱敏。
- 不确定是否合规 → 默认按更严处理，问负责人。
- 食品安全事件（异物/食物中毒投诉/疑似变质）→ 走应急上报，第一时间隔离取证 + 通知 DRI，agent 不得擅自答复顾客承诺赔偿。

> 食品安全无小事。一次食安事故可能摧毁整个连锁品牌——对内对外都宁可保守、宁可停下来核实。
