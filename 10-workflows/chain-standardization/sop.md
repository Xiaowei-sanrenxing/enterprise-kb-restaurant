# 连锁标准化与督导 SOP · 人可读总览

> 给人看的全流程。Agent 执行请走 [`_task-card.md`](_task-card.md)。

## 一句话流程
**标准化**：把样板店全套标准打包成"开店包" → 复刻到新店 → 督导验收过关才转正。
**督导**：拉巡检表逐维度打分 → 一票否决项零容忍 → 问题限期整改 → 复查 → 回流总部(闭环)。

## 几条铁律
1. **SOP 可复制性 = 连锁命根**：标准只在老师傅脑子里 = 开不了第二家好店。一切靠手口传 → 必须沉淀成开店包。
2. **开店包七件套必须齐**：SKU 配方卡 / 设备清单 / 动线布局图 / 岗位编制排班模板 / 培训手册 / 物料清单 / 开业 SOP。缺一件,新店复制就会走样。
3. **督导不止打分,必须闭环**：发现问题 → 限期整改 → 复查 → 回流总部台账。只打分不复查 = 督导白做。
4. **飞检照真实状态**：例行巡店容易"作秀",不提前通知的飞行检查才能查出真实运营。
5. **食安/证照/健康证一票否决**：命中任一 → 直接红牌,不论其他维度多高分;新店缺证 🔴 不得开业(呼应 [`../../90-governance/行业合规默认.md`](../../90-governance/行业合规默认.md))。
6. **配方红线**：配方/央厨工艺 🔴 受限,分级授权,非定版不外传。

## 新店复制时间线（人话版）
筹建(场地/证照/设备进场) → 培训带教(照培训手册练到达标) → 试营业压测(高峰出餐/动线跑通) → 督导验收(逐维度过关 + 食安证照核查) → 转正运营(进常态督导)。
