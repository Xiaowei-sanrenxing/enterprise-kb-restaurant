# 新店复制流程（脱敏示范）

> 核心：**把样板店的全套标准打包成"开店包",一键复刻到新店。SOP 可复制性 = 连锁规模化的命根——标准只在老师傅脑子里,开几家店就是几个味道。**
> （达标线/时长/单价为占位,客户填自己的真实设置）

## 第一步：开店包七件套（标准打包，缺一不可）

| 件 | 内容 | 解决的问题 |
|---|---|---|
| ① SKU 与配方卡 🔴 | 每道菜的用料、克重、工艺步骤、出品标准图 | 出品一致性（同一个味道）|
| ② 设备清单 | 设备型号/数量/摆位/采购或租赁来源 | 后厨产能与复刻一致 |
| ③ 动线布局图 | 前厅+后厨平面图、动线走向、工位分布 | 高峰不堵、效率可复制 |
| ④ 岗位编制与排班模板 | 各岗人数、班次、高峰加排规则 | 人效达标、不缺岗不冗员 |
| ⑤ 培训手册 | 各岗操作 SOP、考核点、带教节奏 | 新人练到达标的依据 |
| ⑥ 物料清单 | 食材/包材/易耗品 SKU + 首批进货量 | 开业不断货、不囤货 |
| ⑦ 开业 SOP | 开业前 N 天倒排清单、试营业脚本、开业当天流程 | 开业不手忙脚乱 |

> ⚠️ 配方卡（①）属 🔴 受限,分级授权、非定版不外传,引用必脱敏。开店包不齐 → 标记**不可开**,不得进入复制流程。

## 第二步：新店复制时间线（五阶段倒排）

```
筹建            场地交付 / 证照办理(营业执照+食品经营许可证) / 设备进场调试 / 首批物料到位
  ↓
培训带教        照培训手册练 → 各岗考核达标 → 后厨配方卡练到出品一致
  ↓
试营业压测      高峰出餐压测 / 动线跑通 / 出餐时长达标 / 试营业脚本走一遍
  ↓
督导验收 ★关卡   按督导巡检表逐维度过关 + 食安证照健康证核查(一票否决)
  ↓
转正运营        进入常态督导节奏,纳入例行巡店+飞检
```

> 督导验收是**硬关卡**：不过关不转正。食安/证照/健康证命中 🔴 → 停止 + 人工确认,agent 不得判定可开业。

## 第三步：复制成功标准（验收看这三条）

| 维度 | 标准 |
|---|---|
| 出品一致性 | 与样板店出品对照,达标率 ≥〔占位 %〕 |
| SOP 落地率 | 培训手册各岗 SOP 实操达标率 ≥〔占位 %〕 |
| 首月达标线 | 首月翻台率/客单价/食材成本率达〔占位线〕 |

## 用法
新店复制第一步永远是核开店包七件套是否齐全(缺项不可开),再按时间线推进,转正前必过督导验收。复制中暴露的"哪个标准没落地" → 回流补全开店包母版（见 [[督导巡检表]] 的整改闭环）。
