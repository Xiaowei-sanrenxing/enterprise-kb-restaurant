# 督导巡检表（脱敏示范，可直接用）

> 核心：**督导不止打分,必须闭环——发现问题 → 限期整改 → 复查 → 回流总部。只打分不复查 = 督导白做。**
> 食安/证照/健康证为**一票否决项**,命中直接红牌,不论总分（呼应 [[行业合规默认]]）。
> （权重/分值/红黄牌线为占位,客户按品牌标准填。）

## 一、分维度巡检打分项（逐项打分）

| # | 维度 | 主要检查项（agent 逐项核） | 否决? |
|---|---|---|---|
| 1 | **食品安全与卫生** | 明厨亮灶到位 / 留样合规 / 食材无过期变质 / 无地沟油等高危行为 / 索证索票台账齐 | 🔴 一票否决 |
| 2 | **证照与健康证** | 营业执照+食品经营许可证有效悬挂 / 全员健康证有效 / 涉酒等许可齐 | 🔴 一票否决 |
| 3 | **库存与效期** | FIFO 先进先出 / 临期效期标识 / 冷链温度达标 / 报损隔离规范 / 账实相符 | 命中变质即转 1 |
| 4 | **出品一致性** | 配方卡用料克重达标 / 出餐时长达标 / 出品对照样板店达标率 / 摆盘标准 | 打分项 |
| 5 | **服务标准** | 接待话术 / 响应速度 / 投诉处理 / 着装仪容 | 打分项 |
| 6 | **现场 5S** | 整理/整顿/清扫/清洁/素养 / 设备保养 / 工位整洁 | 打分项 |
| 7 | **营销执行** | 当期活动物料到位 / 券核销规范 / 价格明码标价无欺诈 | 打分项 |

> 评分：维度 1、2 为一票否决,命中任一 → **直接红牌**,不论其他维度多高分;agent 不得判定门店"巡检合格"。

## 二、飞行检查（飞检）机制

- **为什么飞检**：例行巡店提前通知,门店易临时作秀;**飞检不通知,查的是真实运营状态**。
- **怎么飞**：不预告时间、随机选店、直奔后厨与效期区(最易出问题的地方)。
- **频次**：〔占位：每店每季 ≥N 次〕,问题店加密。

## 三、评分与红黄牌处置

| 结果 | 触发条件（占位线） | 处置 |
|---|---|---|
| 🟢 绿牌 | 总分 ≥〔占位〕且无否决项 | 通过,常态督导 |
| 🟡 黄牌 | 总分〔占位区间〕或有非否决类问题 | 限期整改 + 复查 |
| 🔴 红牌 | 命中食安/证照/健康证否决项,或总分 <〔占位〕 | 立即处置 + 人工确认升级,严重者停业整顿 |

## 四、整改闭环（督导的命根，不止于打分）

```
发现问题        巡检/飞检逐项记录,列问题清单(分维度+严重度)
  ↓
限期整改        下整改单,定责任人+整改期限
  ↓
复查            到期复查,核实是否真改(否决项必现场复查,不接受口头)
  ↓
回流总部        整改结果回流总部台账 → 反复出现的问题回流开店包/培训手册母版迭代
```

## 用法
拉表 → 选类型(例行/飞检)→ 逐维度打分 → 否决项零容忍 → 出问题清单 → 走整改闭环。反复出现的问题不只是单店整改,要回流总部把标准补进 [[新店复制流程]] 的开店包,从源头杜绝。
