# 任务卡 · 连锁标准化与督导（chain-standardization）· 脱敏示范

> Agent 操作总台。接到"新店复制/开店包打包/督导巡检/飞检/整改闭环/出品一致性核查"类任务,从这里开始。
> ★连锁特有：SOP 可复制性 = 连锁规模化的命根。标准没打包好、督导没盯住,开 10 家店就是 10 个味道。

## 🎯 目标(Goal)
让每一家新店都能照着"开店包"复刻出与样板店一致的出品、服务和现场;让每一家老店都被督导按标准盯住,问题发现得了、整改闭得了环。全程不踩三大坑(标准没沉淀只靠老师傅口传/督导只打分不闭环/食安证照红线漏检)。

## 🪜 指令(Instructions)
1. **新店复制类任务**：
   1.1 核开店包是否齐全(SKU 配方卡/设备清单/动线图/排班模板/培训手册/物料清单/开业 SOP)→ 缺项 → 标记不可开
   1.2 按复制时间线推进(筹建→培训带教→试营业压测→督导验收→转正运营)
   1.3 转正前必过督导验收 + 食安证照核查 → 命中红线 🔴 停止 + 人工确认
2. **督导巡检类任务**：
   2.1 选巡检类型(例行巡店 / 飞行检查)→ 拉对应巡检表
   2.2 逐维度打分(食安卫生/出品一致性/服务标准/现场 5S/证照健康证/库存效期/营销执行)
   2.3 一票否决项(食安/证照/健康证)命中 → 直接红牌 → 不论总分
   2.4 出问题清单 → 限期整改 → 复查 → 回流总部台账(闭环,不止于打分)

## 🛠 工具(Tools)
〔门店档案/开店进度读写〕 · 巡检表模板检索 · 〔整改台账读写〕 · 〔出品标准对照库(配方卡 🔴 分级授权)〕

## 🔒 权限(Permission)
- 可读:开店包清单、巡检表、SOP、整改台账、验收标准
- 🔴 受限:配方/央厨工艺/核心 Recipe → 分级授权,非定版不外传,不写入任何对外产物
- 🔴 受限:员工健康证/身份证、供应商报价/单店财务 → 不外发,引用必脱敏
- ⛔ 一票否决(食安/证照/健康证):agent 不得判定门店"通过验收/可开业/巡检合格",必须人工确认
- 需人工确认:新店转正放行、红牌门店处置、整改超期升级

## ✅ 验收(Acceptance)
- 开店包七件套齐全才允许进入复制流程 ｜ 转正前过督导验收 + 食安证照核查
- 巡检逐维度有分、一票否决项零容忍 ｜ 每个问题有"整改→复查→回流"闭环记录
- 详见 evals.md(真实库含)

## 🔄 自我进化接口
每次复制/巡检后记录"哪个标准没落地/哪类问题反复出现 + 卡在哪个维度" → 回流整改台账与开店包母版 → 督导 agent 迭代巡检项、补全开店包缺口(把口传经验沉淀成可复制标准)。
