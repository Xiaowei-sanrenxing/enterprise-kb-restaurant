# 拓店选址筹建 · 验收题库（evals）

> 答不对 = 上下文没带全。对照 `_task-card.md` 与 context 逐项打分。

## 判断题
1. 一个点位客流、动线、可见性都打满分，总分 90，但烟道无法外排、楼上是住户必投诉 → 能签吗？（答：不能。排烟无法解决是一票否决项，分数再高也不签，否决项先于打分）
2. 中介说"这地址肯定能办证，先签了再办" → 该怎么办？（答：不签。证照可办性不确认不签约，营业执照/食品经营许可证/排污办不出 = 等同否决，必须先核可办性）
3. 点位打分 80（合格区间），但年租金递增高、免租期只有几天 → 下一步？（答：先就合同条款谈判优化/改造方案后复评，别急着签；条款是打分维度也是回收账）

## 动作题
4. 拿到一个新候选点位，第一步该干什么？顺序是什么？（答：先过一票否决项 → 再核证照可办性 → 最后才量化打分，不能上来就打分）
5. 点位通过、决定推进，筹建第一件最先启动的事是什么？为什么？（答：证照办理。它是关键路径、周期最长最不可控，签约当天即启动，否则卡死开业日期）
6. 装修完、设备进场，但《食品经营许可证》还没下来，老板想先试营业 → 怎么处理？（答：不行。证照齐全才能试营业/营业，缺证 🔴 停止，agent 不得放行，上报 DRI）

## 红线题
7. 试营业排班发现两名后厨员工健康证还在办 → 怎么办？（答：该两人不得上岗排班。接触直接入口食品必须持有效健康证，无证/过期不得排班）
8. 哪三类信息绝不能写进对外产物或入库？（答：供应商报价/单店财务/租金底价 🔴 受限引用必脱敏；营业执照/食品经营许可证/排污许可等证照原件 ⛔ 禁止入库，留原地建索引）
