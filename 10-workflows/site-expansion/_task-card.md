# 任务卡 · 拓店选址筹建（site-expansion）· 脱敏示范

> Agent 操作总台。接到"评估点位/横评铺子/算租售比/排筹建计划/核证照"类任务，从这里开始。

## 🎯 目标(Goal)
把一个候选点位，从初筛推进到"签约决策 + 筹建开业落地"，全程不踩三大坑（凭感觉签约/证照可办性没核就签/缺证就开业）。

## 📥 上下文(Context) —— 动手前必读全
1. [`context/选址评分模型.md`](context/选址评分模型.md) — 先过否决项→核证照可办性→再打分
2. [`context/筹建开业Checklist.md`](context/筹建开业Checklist.md) — 签约到开业的筹建甘特与三道合规闸
3. 〔餐饮合规默认〕 — 食品安全/证照红线（真实库 `90-governance/行业合规默认.md`）
4. 〔历史开店/关店复盘〕 — 必须避开的踩坑点位（真实库含此项）

## 🪜 指令(Instructions)
1. 拿到候选点位 → 先过**一票否决项**（排烟不可解/物业禁餐饮/证照不可办/水电排污不达标且不可改）
2. 命中否决项 → 🔴 停止推进 + 标注原因，不用其他维度高分对冲
3. 未命中 → **核证照可办性**（营业执照/食品经营许可证/排污/消防），办不出 = 等同否决
4. 通过 → 用打分卡逐维度量化打分（多点位横评）
5. 按阈值判级 → 优质点位进筹建，边际点位交 DRI 评审
6. 签约前最后一道闸：再确认证照可办性
7. 点位定 → 启动 [`context/筹建开业Checklist.md`](context/筹建开业Checklist.md)，证照办理为关键路径最先启动
8. 试营业/开业前：证照齐全 + 全员持健康证 + 明厨亮灶达标，三项全过才放行

## 🛠 工具(Tools)
〔点位档案读写〕 · 选址打分卡模板 · 〔租售比/坪效测算表〕 · 〔筹建甘特/Checklist 模板〕

## 🔒 权限(Permission)
- 可读：选址模型、筹建 Checklist、合规默认、复盘
- 🔴 受限：供应商报价/单店财务测算/租金底价 → 不得写入任何对外产物，引用必脱敏
- ⛔ 禁止入库：营业执照/食品经营许可证/排污许可等证照原件 → 留原地建索引
- 需人工确认：超预算签约、边际点位拍板、**任何缺证开业/试营业（红线，agent 不得放行）**

## ✅ 验收(Acceptance)
- 否决项先过 ｜ 证照可办性已核 ｜ 打分有量化依据 ｜ 缺证不签不开 ｜ 健康证齐才排班 ｜ 明厨亮灶达标
- 详见 evals.md

## 🔄 自我进化接口
每个点位记录"签约/放弃 + 开业后实际坪效 vs 预估 + 踩了哪条坑" → 回流复盘数据 → 校准打分权重与否决项，让模型越用越准。
