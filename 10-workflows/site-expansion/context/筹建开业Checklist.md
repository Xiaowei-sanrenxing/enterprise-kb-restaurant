# 筹建开业 Checklist · 从签约到开业（脱敏示范）

> 点位通过 [[选址评分模型]] 后启动。**核心铁律：证照齐全才能营业，员工持健康证才能上岗，后厨必须明厨亮灶。** 缺证 = 🔴 停止开业。
> （工期天数用「〔〕」占位，按品类与城市填自己的真实工期）

## 筹建阶段甘特（六段并行/串行，关键路径是"证照")
```
签约
 ├─ ① 证照办理（关键路径，最先启动）───────────────┐
 ├─ ② 设计施工（消防/排烟/明厨亮灶）──────┐         │
 │        └─ ③ 设备采购进场 ──┐          │         │
 │                            ↓          ↓         ↓
 ├─ ④ 招聘培训（健康证）─────────────────┘         │
 │                                                  ↓
 └────────────────────→ ⑤ 试营业压测 ──→ ⑥ 正式开业
```
> ⚠️ 证照办理周期最长、最不可控，**签约当天即启动**，否则它会卡死整个开业日期。

## ① 证照办理（🔴 关键路径，不齐不得营业）
- [ ] 《营业执照》（核对经营范围含餐饮/食品）
- [ ] 《食品经营许可证》（功能分区、面积、设备需先达标才受理）
- [ ] 《排污许可》/ 环保手续（油烟、污水）
- [ ] 消防：消防安全检查合格 / 二次消防报审（如需）
- [ ] 涉酒类、户外摆台、特殊品类的对应许可
> 缺任一证 → 🔴 不得开业/试营业，agent 不得拍板放行，上报 DRI 人工确认。

## ② 设计施工（合规优先于美观）
- [ ] 平面布局符合食品经营许可功能分区（生熟分开、洗消区、库房）
- [ ] **排烟系统**：油烟净化达标、烟道走向经物业/环保认可
- [ ] **消防工程**：通道、报警、灭火设施按报审执行
- [ ] **明厨亮灶**：透明厨房/视频公示/玻璃隔断（满足当地标准之一，呼应合规红线）
- [ ] 上下水、隔油池、强弱电按餐饮负荷施工

## ③ 设备采购进场
- [ ] 厨房设备清单按出餐 SOP 配齐（灶/冰柜/操作台/洗消）
- [ ] 冷链设备到位并验温（冷藏/冷冻达标，呼应温度管控红线）
- [ ] 前厅设备（收银/POS/桌椅/外卖打包台）
- [ ] 设备进场与施工节点对齐，避免装修返工

## ④ 招聘培训（🔴 健康证红线）
- [ ] 按编制招齐前厅/后厨
- [ ] **所有接触直接入口食品的员工持有效《健康证》方可上岗**（无证/过期 → 不得排班）
- [ ] 出餐 SOP / 服务 SOP / 食品安全培训到位
- [ ] 索证索票、留样、FIFO、报损流程培训并考核

## ⑤ 试营业压测
- [ ] 证照确认齐全后方可试营业（缺证不得试营业）
- [ ] 全员健康证齐全后方可排班
- [ ] 高峰压测：出餐时长、动线、设备负荷
- [ ] 留样制度、温度记录、台账当天即跑起来
- [ ] 收集问题清单 → 整改 → 复评

## ⑥ 正式开业
- [ ] 证照齐全 + 全员持证 + 明厨亮灶达标 三项全过（任一不过 → 不得开业）
- [ ] 食安自查表过关
- [ ] 开业活动物料经合规审核（菜单/海报不得虚假夸大）

## 用法
点位过评后照此清单推进筹建，证照是关键路径需最先启动。三道合规闸（证照齐全 / 持证上岗 / 明厨亮灶）任一不过 → agent 立即停止开业并上报。
