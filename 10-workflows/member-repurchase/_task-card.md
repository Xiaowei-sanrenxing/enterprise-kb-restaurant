# 任务卡 · 会员与复购（member-repurchase）· 脱敏示范

> Agent 操作总台。接到"会员入会/分层触达/复购唤醒/外卖运营/差评处理"类任务，从这里开始。

## 🎯 目标(Goal)
把一个到店/外卖顾客，沉淀成可反复触达的会员，按消费频次分层、按节奏触达拉复购，把首单变二单、二单变常客，全程不踩三大坑（入会断点 / 全员一套话术群发 / 沉睡了才想起捞）。

## 📥 上下文(Context) —— 动手前必读全
1. [`context/会员分层与复购节奏.md`](context/会员分层与复购节奏.md) — RFM 思路 30 秒判层 + 分层触达节奏表
2. [`context/外卖运营SOP.md`](context/外卖运营SOP.md) — 菜单定价/活动配置/履约时效/评分差评处理
3. [`../../90-governance/行业合规默认.md`](../../90-governance/行业合规默认.md) — 顾客数据红线 + 食安封签
4. 〔会员系统/小程序后台〕 — 会员标签、储值、券核销（真实库含此项）
5. 〔历史复购数据〕 — 各层复购率/核销率基线（真实库含此项）

## 🪜 指令(Instructions)
1. 入会：到店扫码进企微/社群/小程序会员 → 发新客首单券，把入会做成出餐/结账动作的一环，禁断点
2. 打标分层：按 RFM（最近一次/频次/金额）判 高频/活跃/沉睡/流失 四层
3. 按层走触达节奏（见节奏表），禁全员一套话术群发
4. 新客 7 日内推二次到店钩子（二单券）→ 活跃客推储值/付费会员
5. 沉睡客主动唤醒（限时唤醒券），不等流失才捞
6. 外卖单：按外卖 SOP 配菜单定价/活动/履约，盯评分，差评按话术处理
7. 每轮触达回收复购率/核销率 → 回流数据，迭代节奏与权益

## 🛠 工具(Tools)
〔会员系统/小程序后台读写〕 · 〔企微/社群群发工具〕 · 〔外卖平台商家后台〕 · 〔券与储值配置台〕

## 🔒 权限(Permission)
- 可读：分层标准、触达节奏、权益规则、外卖 SOP、差评话术
- 🔴 受限：顾客姓名/手机/微信/地址/订单记录/会员数据 → 不得写入任何对外产物，引用必脱敏
- 需人工确认：超标准的券面额/储值返利、群发文案对外发布、高风险差评赔偿（不承诺超额赔偿，走人工）

## ✅ 验收(Acceptance)
- 入会无断点 ｜ 分层用 RFM 不群发 ｜ 沉睡主动唤醒 ｜ 外卖带食安封签 ｜ 差评不承诺超额赔偿
- 顾客数据全程脱敏，不外发
- 详见 evals.md

## 🔄 自我进化接口
每轮触达记录"层级 + 触达动作 + 复购/核销结果" → 回流复购数据 → 监控 agent 优化分层阈值、节奏与权益面额。
