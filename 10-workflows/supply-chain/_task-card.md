# 任务卡 · 供应链与采购（supply-chain）

> Agent 操作总台。接到"算成本率/排查成本异常/下单/到货验收/拒收/进货台账/溯源/库存盘点"类任务，从这里开始。

## 🎯 目标（Goal）
把食材从采购到入库管住两条命脉：**成本率守在目标区间**（不超标）、**食品安全不出事**（索证索票/冷链/溯源/拒收变质一项不漏）。任何超标或合规风险，预警 + 归因 + 上报，不擅自放行。

## 📥 上下文（Context） —— 动手前必读全
1. [`context/食材成本控制法.md`](context/食材成本控制法.md) — 成本率怎么算、超标怎么排查归因
2. [`context/采购验收与溯源SOP.md`](context/采购验收与溯源SOP.md) — 下单到验收标准、拒收流程、台账与溯源
3. 〔供应商档案/比价表〕 — 定点供应商资质、报价（🔴 受限，真实库含此项）
4. 〔标准 Recipe 卡库〕 — 标准化分量，控成本基准（真实库含此项）
5. [`../../90-governance/行业合规默认.md`](../../90-governance/行业合规默认.md) — 食安红线，验收/采购前逐条过

## 🪜 指令（Instructions）
1. **采购前**：核供应商资质（索证索票齐不齐）→ 比价定点 → 按销量预测/库存下单（防积压防断货）
2. **到货时**：按验收标准逐项查——数量 / 质量 / 温度（冷链）/ 保质期 / 检验检疫证明
3. 不合格 → 走拒收流程，不入库、不上账、留证拍照、通知 DRI
4. **入库**：录进货台账（来源可追）→ 按 FIFO 上架 → 冷链不断链
5. **算成本**：按公式算食材成本率 → 对比目标区间〔30%~40%占位〕
6. **超标**：走「成本率异常排查清单」逐项归因（采购涨价/损耗/分量失控/盗损）→ 定位 → 给整改动作
7. 命中食安红线（变质/缺证/断链/无台账）→ 🔴 立即停止 + 人工确认

## 🛠 工具（Tools）
〔进销存/库存系统读写〕 · 〔供应商档案与比价表〕 · 标准 Recipe 卡检索 · 〔成本率看板〕 · 〔进货台账/溯源系统〕

## 🔒 权限（Permission）
- 可读：验收标准、SOP、Recipe 卡、台账模板、成本率公式
- 🔴 受限：**供应商报价 / 进货价 / 毛利率 / 单店财务数据**（核心商业机密，决定生死）→ 不得写入任何对外产物，引用必脱敏
- 🔴 受限：配方/中央厨房工艺/核心 Recipe → 分级授权，非定版不外传
- ⛔ 禁止入库：食品经营许可证/营业执照等证照原件 → 留原地建索引
- 需人工确认：更换主力供应商、超阈值的临期食材处理、成本率持续超标的提价/换料决策

## ✅ 验收（Acceptance）
- 到货必过 5 项验收（数量/质量/温度/保质期/检疫证明）｜ 不合格必拒收留证
- 每笔进货有台账、来源可追去向可查 ｜ 冷链全程不断链 ｜ FIFO 执行
- 成本率算对、超标必归因有整改 ｜ 受限数字不外泄
- 详见 [`evals.md`](evals.md)

## 🔄 自我进化接口
每次验收/拒收/成本超标记录"问题类型 + 归因 + 整改动作 + 是否复发" → 回流〔供应商档案 + 成本异常台账〕 → 高频拒收的供应商进黑名单、高频超标的菜品回推标准 Recipe 卡修订 → 监控 agent 定期复盘优化定点与分量标准。
