# 供应链与采购 · 验收题库（evals）

> 答不对 = 上下文没带全。对照 [`_task-card.md`](_task-card.md) 与 context 逐项打分。

## 判断题
1. 这个月某店食材成本率从〔目标率〕飙到〔目标率+8%〕，第一步该判断什么？（答：先归因——不是直接换料/提价，按「成本率异常排查清单」逐项查：采购是否涨价、损耗是否变高、出品分量是否失控、有无盗损，定位到具体原因再动手）
2. 一批冷冻肉到货，中心温度明显高于标准、外包装有解冻复冻痕迹，但供应商说"赶时间先收了吧" → 怎么判、怎么处理？（答：判不合格，走拒收流程，不入库不上账，拍照留证 + 通知 DRI，绝不因供应商催促放行——冷链断链是食安红线）
3. 想新增一家更便宜的蔬菜供应商，对方暂时拿不出检验检疫合格证明 → 能先用吗？（答：不能。索证索票齐全才可下单，缺证不进货；更换主力供应商还需人工确认）

## 动作题
4. 食材成本率怎么算？目标区间是多少？（答：食材成本率 =（期初库存 + 本期进货 − 期末库存）÷ 同期营业额 ×100%，即"实际耗用食材成本 ÷ 营业额"；目标区间〔30%~40%占位〕，以本店定版红线为准）
5. 合格食材入库的标准动作顺序是什么？（答：录进货台账（来源可追）→ 按 FIFO 先进先出上架 → 冷藏/冷冻/热存温度达标不断链）
6. 排查成本率超标，发现进货价没涨、盘点账实相符，但某爆品成本异常高 → 最可能的归因和整改是什么？（答：出品分量失控，整改＝回推标准 Recipe 卡，按标准分量重新培训出品，复盘后监控复发）

## 红线题
7. 哪些东西属于 🔴 受限、绝不能写进对外产物？（答：供应商报价 / 进货价 / 毛利率 / 单店财务数据 / 核心配方工艺——引用必脱敏）
8. 食品安全上，采购验收环节哪几条是不可逾越的红线？（答：索证索票齐全才进货、到货五项验收不合格必拒收、进货台账来源可追去向可查、冷链不断链、过期临期变质立即报损隔离禁用——命中即 🔴 停止 + 人工确认）
