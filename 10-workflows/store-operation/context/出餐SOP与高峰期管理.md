# 出餐 SOP 与高峰期管理

> 核心：**出品一致 + 出餐快**是门店运营的两条命。一致靠标准 Recipe，快靠提前排产与高峰调度。
> （出餐时长目标 / 备料量 / 排班人数为客户专属，用〔〕占位，填自己门店真实标准。）

## 一、开店准备（开门前）
- **备料**：按〔当日预估客流/峰量〕备足净菜、半成品、料包；遵守 FIFO，临期食材优先用、过期立即报损隔离。
- **设备检查**：灶具/冰柜/保温/制冰/收银/叫号系统逐项通电测试；冷藏/冷冻温度达标（详见 [[食品安全与卫生标准]]）。
- **卫生**：开业前卫生检查项全过（详见 [[食品安全与卫生标准]]）；员工健康证、穿戴、洗手到位才上岗。
- 三项任一不达标 → 整改后才开门；命中食安隐患 → 🔴 停，走食安流程。

## 二、接单出餐标准流程
1. **接单**：前厅录单 → 后厨叫单/打印，确认桌号、品项、特殊要求（少辣/忌口/过敏原）。
2. **标准 Recipe**：严格按〔标准 Recipe〕操作工序，不凭手感、不省步骤——这是出品一致性的唯一基准。
3. **标准分量**：按〔标准分量表〕称量/控量，杜绝多给少给造成的成本与体验波动。
4. **出餐时长**：盯〔出餐时长目标（占位）〕，从下单到上桌计时；超时单记录回流。
5. **前后厨协同**：后厨出餐 → 划单/报菜 → 前厅传菜核对桌号品项 → 漏单/错单当场纠。
6. **出品检查**：出门前看卖相/温度/分量，不达标即返工，不让次品出门。

## 三、高峰期管理
- **排班峰谷匹配**：按〔峰谷客流数据〕排班，午晚高峰加岗、平峰减岗，避免高峰缺人、平峰窝工。
- **备料按峰量**：高峰前完成预制/补料，半成品提前到位，减少现场加工时间。
- **限流与叫号**：满座时启用叫号/取号，控制进店节奏，避免后厨爆单导致全面超时。
- **加单/安抚话术**：用标准话术管理等位与催菜预期（如告知预计等位时长、主动报菜进度），稳住体验。
- **后厨节奏控制**：按叫单顺序控火出餐，先到先做 + 急单插队规则清晰，不积单不漏单。

## 四、收市盘点（打烊后）
- **清洁复位**：后厨/前厅/设备清洁，按收市卫生检查项执行（详见 [[食品安全与卫生标准]]）。
- **盘点对账**：食材/物料实物盘点对账面，标记损耗、临期；报损按流程登记。
- **留样核对**：核对当日各餐次留样是否齐全、标签时间是否规范。
- **废弃物交接**：餐厨垃圾/废油交有资质单位并留台账。
- **报表回流**：当日营业额、出餐超时单、报损、客流回流运营数据，供复盘。

## 核心指标
- **翻台率**：单时段餐桌使用次数，运营效率核心。
- **出餐速度（出餐时长）**：高峰体验与翻台的关键。
- **出品一致性**：连锁可复制的根基，靠标准 Recipe + 标准分量保障。
