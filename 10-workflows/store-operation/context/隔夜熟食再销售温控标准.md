# 隔夜/熟制食品再销售温控标准（操作 SOP）

> 补盲区：库原只有"过期禁用/报损隔离"的一般红线，本卡给"剩菜到底能不能卖、怎么卖"的可执行阈值。
> 核心：能不能再卖，看**全程温控 + 时限 + 复热 + 性状**四关，任一不过 = 必弃。给的是通用食安标准，本店更严阈值填〔占位〕。

## 四关判定（全过才可再售）
| 关 | 通用标准 | 本店阈值 |
|---|---|---|
| 1 冷藏温控 | 熟食出餐后 2 小时内未售须冷藏（冷藏 ≤8℃ 或 冷冻）；常温久置一律弃 | 〔填本店冷藏温度〕 |
| 2 存放时限 | 冷藏熟食再售存放不超过本店设定时限，超时必弃 | 〔填本店时限，建议 ≤24h〕 |
| 3 复热 | 再售前充分复热至**中心温度 ≥70℃**（高风险品类建议 ≥75℃）；**只可复热一次** | 〔本店若更严填此〕 |
| 4 性状 | 变味/发黏/变色/异味/胀袋 → 一律废弃，不冒险 | — |

## 高风险品类（更严或直接不隔夜再售）
凉拌菜、海鲜水产、蛋制品、奶/豆制品、溏心类 → 建议**当日售罄不隔夜再售**（本店按〔品类清单〕收紧）。

## agent 标准动作
1. 老板/店长问"隔夜 X 能不能卖" → 按四关逐条核：缺温控记录/超时限/不能复热到 70℃/性状异常 → **判不可售、报损**。
2. 四关全过且属可隔夜品类 → 可售，但须复热达标 + 留样。
3. 涉及食安拿不准 → **默认从严禁售**，转门店运营 DRI，宁可报损不冒中毒风险。

## 红线
- 🔴 变质/超时/复热不达标的熟食再售
- 🔴 高风险品类隔夜再售（除非本店明确允许且全程达标）
