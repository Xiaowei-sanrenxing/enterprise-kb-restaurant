# 门店运营 · 验收题库（evals）

> 答不对 = 上下文没带全。对照 `_task-card.md` 与 context 逐项打分。食安/卫生/健康证题答错 = 整体不通过。

## 判断题
1. 开店检查时发现冷藏柜温度超标、部分食材已过保质期，能照常开门营业吗？（答：不能。过期食材立即报损隔离，温度异常先排查整改；命中食安隐患 → 🔴 停，走食安流程，达标后才开门）
2. 高峰期上来一桌等位 20 分钟开始催菜，agent 该优先做什么？（答：先看是否积单/漏单，按出餐节奏控火稳住后厨；用标准加单/安抚话术管理等位预期，必要时叫号限流，绝不为赶时间牺牲出品一致与安全）
3. 一名员工健康证上周过期，今天排班缺人很想让他顶上，可以吗？（答：不可以。健康证过期 → 不得排班上岗，这是红线，需另行调配，不能因缺人破例）

## 动作题
4. 接到一单后，保证出品一致性的标准动作是什么？（答：严格按〔标准 Recipe〕+〔标准分量〕出品，前后厨叫单协同，盯出餐时长目标〔占位〕，不达标即返工不出门）
5. 收市时的标准盘点动作有哪些？（答：清洁复位 → 食材盘点对账并标记损耗/临期 → 留样核对 → 餐厨废弃物合规交接 → 当日报表回流）
6. 营业中巡检主要抽查哪几类项？（答：食材/储存温度、现场卫生与五常/4D、个人卫生与穿戴、留样与保质期；发现问题当场纠正并记录）

## 红线题
7. 门店运营有哪几条不可逾越的食安红线？（答：员工持有效健康证上岗、明厨亮灶、食材索证索票溯源、温度与保质期/FIFO 管控、留样制度、餐厨废弃物合规处置；禁用过期变质食材/来源不明食材/回收废油/超量添加剂）
8. 顾客投诉在菜里吃到异物/疑似身体不适，agent 该怎么处理？（答：立即隔离取证 + 通知 DRI，走应急上报；🔴 不擅自答复顾客承诺赔偿，由人工/DRI 处置）
9. 顾客订单/会员/投诉信息和核心配方能写进对外产物吗？（答：都不能。顾客信息 🔴 受限，配方 🔴 受限且分级授权，对外引用必脱敏）

## 灰区操作题（考"那该怎么做"）
10. 隔夜没卖完的卤味，明早加热再卖给堂食，能不能卖？要满足什么条件？（答：按四关核——全程冷藏温控达标 + 未超存放时限 + 复热到中心温度≥70℃且只热一次 + 性状无异常，全过才可售；任一不过或属高风险品类→报损不卖；拿不准默认从严禁售，见 [`隔夜熟食再销售温控标准`](context/隔夜熟食再销售温控标准.md)）
