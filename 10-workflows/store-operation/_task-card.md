# 任务卡 · 门店运营（store-operation）

> Agent 操作总台。接到"开店准备/出餐排产/高峰期调度/卫生巡检/收市盘点/食安事件处置"类任务，从这里开始。

## 🎯 目标（Goal）
让单店在一个营业日内，把出品做到"一致 + 快 + 安全"——开店达标、出餐稳定、高峰不崩、收市盘清，全程不踩食品安全红线。

## 📥 上下文（Context） —— 动手前必读全
1. [`context/出餐SOP与高峰期管理.md`](context/出餐SOP与高峰期管理.md) — 开店→出餐→高峰→收市全流程动作
2. [`context/食品安全与卫生标准.md`](context/食品安全与卫生标准.md) — 三时段卫生检查 + 食安红线 + 应急上报（生命线，必读）
3. [`context/隔夜熟食再销售温控标准.md`](context/隔夜熟食再销售温控标准.md) — 剩菜/隔夜熟食能不能再卖：温控/时限/复热70℃/性状四关
4. 〔标准 Recipe 库 / 标准分量表〕 — 客户补：出品一致性的唯一基准（🔴 配方受限）
4. 〔门店排班表 / 峰谷客流数据〕 — 客户补：排班峰谷匹配依据

## 🪜 指令（Instructions）
1. **开店准备**：按检查表过备料/设备/卫生三项 → 任一不达标 → 整改后才开门；食材温度/保质期/留样设备命中异常 → 🔴 停，走食安流程。
2. **接单出餐**：严格按〔标准 Recipe〕+〔标准分量〕出品 → 前后厨叫单协同 → 盯出餐时长目标〔占位〕→ 出品不达标即返工，不出门。
3. **高峰期管理**：排班按峰谷匹配 → 必要时限流/叫号 → 用标准加单话术安抚等位 → 后厨按出餐节奏控火，不积单不漏单。
4. **营业中巡检**：按食安检查表抽查温度/卫生/个人穿戴 → 发现问题当场纠正并记录。
5. **收市盘点**：清洁复位 → 食材盘点对账（损耗/临期标记）→ 留样核对 → 餐厨废弃物合规交接 → 当日报表回流。
6. **食安事件**：异物/疑似变质/顾客身体不适投诉 → 立即隔离取证 + 通知 DRI，走应急上报，**agent 不擅自答复顾客承诺赔偿**。

## 🔒 权限（Permission）
- 可读：出餐 SOP、卫生标准、检查表、巡检记录
- 🔴 受限：顾客个人信息（投诉记录/订单/会员）→ 不得写入任何对外产物；核心配方/Recipe → 分级授权，非定版不外传
- 需人工确认：缺证照/员工健康证过期是否上岗、食安事件对外答复、超标准报损
- ⛔ 红线：员工健康证缺失/过期 → 不得排班上岗；食材过期变质 → 禁用、报损隔离，详见 [`context/食品安全与卫生标准.md`](context/食品安全与卫生标准.md)

## ✅ 验收（Acceptance）
- 开店三项达标 ｜ 出品符合标准 Recipe/分量 ｜ 出餐时长达标〔占位〕｜ 高峰不积单漏单 ｜ 收市盘清账平 ｜ 留样合规 ｜ 全程零食安红线
- 食安/卫生/健康证项不通过 = 整单不通过，详见 evals.md

## 🔄 自我进化接口
每个营业日记录"出餐超时单 / 高峰卡点 / 巡检不合格项 / 食安隐患" → 回流运营数据 → DRI 复盘优化 SOP、排班与备料量，沉淀成新标准。
