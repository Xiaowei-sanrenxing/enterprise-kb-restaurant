# DRI 责任地图（极薄组织上下文）

> 不是部门墙,只回答:每条工作流,谁是那个被命名的负责人(DRI)。
> AI Native 公司不靠"部门",靠"每件事一个 DRI"。

| 工作流 / 域 | DRI | 职责 |
|---|---|---|
| 拓店选址筹建 | 〔DRI〕 | 选址评估、筹建开业 |
| 供应链与采购 | 〔DRI〕 | 食材采购、成本控制、库存管理 |
| 门店运营 | 〔DRI〕 | 出餐SOP、服务、卫生标准 |
| 会员与复购 | 〔DRI〕 | 私域、会员、外卖运营 |
| 连锁标准化与督导 | 〔DRI〕 | 新店复制、督导巡检（连锁特有） |
| 知识库治理 | 〔知识库负责人〕 | 准入/定版/权限/同步 |

> 注:初期可单人多角色,团队扩张后每条工作流的 DRI 拆给具体的人,原则不变。
