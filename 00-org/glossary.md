# 餐饮（连锁）行业 黑话词典 · 让 agent 看懂内部术语

> 行业通用术语已预填。公司专属术语 / 人物 / 产品请客户补在文末。

## 业务术语（行业通用）
- **翻台率**：同一餐桌一个营业时段被使用的次数，衡量门店坪效与运营效率的核心指标。
- **客单价**：每位顾客平均消费金额（营业额 ÷ 顾客数），与翻台率共同决定单店营收。
- **坪效**：每平方米营业面积创造的营业额，选址与店型评估的关键。
- **人效**：人均产出（营业额 ÷ 员工数），衡量人力配置是否合理。
- **毛利率**：（售价 − 食材成本）÷ 售价，餐饮命门，受食材成本与定价影响。
- **食材成本率（Food Cost）**：食材成本 ÷ 营业额，行业通常控制在 30%~40%，是成本控制第一指标。
- **三大成本**：食材（Food）、人力（Labor）、租金（Rent），合称餐饮成本三座大山。
- **出餐**：从下单到菜品上桌的全过程；**出餐时长/出餐速度**是高峰期体验与翻台的关键。
- **SKU**：菜单上的单个销售品项；菜单精简 = 砍 SKU。
- **爆品/引流品**：高人气或低价引流的招牌菜，带动客流与连带销售。
- **连带率**：顾客平均购买的品项数，衡量搭配销售与菜单设计能力。
- **报损/损耗**：因变质、过期、操作失误等造成的食材或成品损失。
- **FIFO（先进先出）**：库存管理铁律，先入库的食材先使用，防过期。
- **盘点**：定期清点库存实物与账面是否一致，发现损耗与漏洞。
- **索证索票**：进货时索取供货方资质与检验合格证明，食材溯源的合规动作。
- **明厨亮灶**：后厨可视化（透明/视频/玻璃），食品安全合规要求。
- **留样**：每餐次成品按规定留存样本备查，食安溯源制度。
- **中央厨房（央厨/中厨）**：集中加工配送的后端工厂，连锁标准化与降本核心。
- **净菜/半成品/料理包**：央厨预处理后配送到店的食材形态，决定门店操作难度与一致性。
- **前厅/后厨（前场/后场）**：前厅=服务接待区，后厨=加工出餐区。
- **督导/巡店**：总部派人到门店检查标准执行情况，连锁管控的关键岗位。
- **飞行检查（飞检）**：不提前通知的突击巡检，查真实运营状态。
- **巡检表/检查表（Checklist）**：督导按项打分的标准化工具。
- **SOP**：标准作业流程，连锁可复制的基础（出餐 SOP/服务 SOP/开店 SOP）。
- **新店复制/开店包**：把一家成熟门店的全套标准打包，供新店快速复刻。
- **样板店/标杆店**：作为标准范本供复制和参观学习的门店。
- **私域**：可反复触达的自有顾客流量池（企微/社群/小程序会员）。
- **复购率**：顾客在一定周期内再次消费的比例，餐饮 LTV 核心。
- **核销**：顾客使用优惠券/团购券/会员权益的兑现动作。
- **外卖运营**：在外卖平台的上架、定价、活动、评分、出单管理。
- **堂食/外带/外卖（堂、带、卖）**：三大消费场景，渠道结构影响成本与定价。

## 本体系关键概念（跨工作流复用）
- **工作流**：一件能整个交给 agent 干完的事（选址/采购/运营/复购/督导），是本库组织主轴。
- **任务卡 6 要素**：目标/上下文/指令/工具/权限/验收，每条工作流一张。
- **选址评分模型**：拓店第一步，量化打分决定是否签约（见拓店工作流）。
- **食材成本率红线**：供应链核心控制指标，超标即预警（见供应链工作流）。
- **出餐 SOP**：门店运营可复制的标准动作，决定一致性与速度（见门店运营工作流）。
- **会员分层/复购节奏**：按消费频次分层，按节奏触达拉复购（见会员与复购工作流）。
- **新店复制流程 + 督导巡检表**：连锁标准化的两大抓手（见连锁标准化工作流）。
- **食品安全红线**：贯穿采购/运营/督导的不可逾越底线（见合规默认）。
- **双区/定版**：草稿区/定版区/归档区，配方与 SOP 定版才可复制下发。
- **受限/脱敏**：顾客信息、供应商报价、配方工艺受限，对外引用必脱敏。
